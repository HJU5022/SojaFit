## 2. 방법

| 단계 | 내용 |
|---|---|
| 1 | 던져버릴 `git worktree`(분리된 HEAD)에 변이 대상 커밋을 내려받는다 |
| 2 | 변이 파일에서 `before` 문자열이 정확히 1곳일 때만 `after`로 바꾼다. N12는 `evals/dataset_v1.jsonl` 끝에 공백 1바이트를 붙인다 |
| 3 | 지정 시험을 돌린다. 실패하면 CAUGHT 후보 |
| 4 | `git checkout -- <파일>`로 원복하고 같은 시험을 다시 돌린다. 통과해야 한다 |
| 5 | `git status --porcelain`과 `git diff --stat`이 비어 있는지 확인한다 |
| 판정 | CAUGHT = 변이 시 실패 + 원복 뒤 통과 + 작업 트리 깨끗. NOT_CAUGHT = 변이 시 통과 |

| 파일 | 내용 |
|---|---|
| [mutation/reproduce.sh](mutation/reproduce.sh) | 1~5단계와 기준 미달 시연을 한 번에 돈다 |
