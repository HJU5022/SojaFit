- 결론: D1은 플라이백 보호 다이오드로, Q1이 켜져 부저에 전류가 흐를 때는 역바이어스되어 거의 전류가 흐르지 않습니다. Q1을 끄면 코일 전류가 LS1 N → D1 애노드 → 캐소드 → LS1 P → 코일 → N으로 순환하며 감쇠하여 Q1의 과전압을 억제합니다.
