- 사전 등록 기준 대조: 대상 평균이 줄지 않아 의미 있는 단축(2초)에 못 미친다("효과 없음"을 넘어 증가). p95도 두 회차 모두 R1보다 크다(10.5 → 34.4초, 12.1 → 25.3초). 대상 문항이 답으로 바뀐 경우는 없다. 관련 문항 판정 변화는 위 v3-41 · v3-15다.
