## 2. 입력 격리 확인 `[실측]`

받은 zip(`terra_web_baseline.zip`, 208파일)을 빈 폴더에 풀어 조장 쪽에서 다시 확인했다.

- 50개 요청 모두 메시지가 system 1개 + user 1개다. 요청 설정 50개가 모두 같다: `max_tokens` 8192, reasoning `medium`, `plugins` web/native, provider `allow_fallbacks: false` · `data_collection: deny`, `stream: false`.
- user 메시지의 질문 글은 `evals/guides/v3_50_codex_paste.md`의 문항 본문과 같다. 머리의 관련/비관련 표지는 빠졌고, 넷리스트 줄만 `./circuit.net (아래에 전체 내용 제공)`으로 바뀌었다. 50/50 일치.
- user 메시지 뒤에 붙은 넷리스트 전체 내용은 저장소의 그 문항 넷리스트 파일과 같다. 50/50 일치.
- 요청 안에 저장소 · 평가 용어(SojaFit, AGENTS, CLAUDE, 판정 5종 이름, dataset_v3, relevant/irrelevant, 정답 등)가 없다.
- 모든 문항이 `answered`이고 `finish_reason`은 `stop`이다. 응답 모델은 요청 모델과 같다.
- 결과물 안에 API 키 모양의 문자열이 없다.
- 확인하지 못한 것: 모델의 사전학습 데이터, 그리고 공급자가 내부에서 무엇을 보관하는지.

zip의 `answers.txt`는 `answers.md`와 바이트가 같아서 넣지 않았다. 실행 스크립트는 `scripts/run_isolated_baseline.py`에 실행 기록으로만 둔다. OpenRouter를 직접 부르는 코드라서 저장소 코드로 쓰지 않는다(AGENTS 지킬 것 2번).

## 5. 한계

- **도메인 밖 6문항(v3-26~31)의 환각 위험 6건**: 격리 입력에는 "이 서비스는 다이오드 대체만 다룬다"는 범위가 없다. 그래서 릴레이 · 게이트 드라이버 · 변압기를 추천한 것은 받은 질문에 대한 답일 수 있다. 이 6건을 Terra의 환각으로 단정하지 않는다 [추정]. 정답은 그대로 둔다.
- 사람 판정 15건과 4절의 규칙 오판 의심이 정해지기 전에는 `EVAL_REPORT.md` · `README.md`의 Codex 비교 숫자(45/50)를 바꾸지 않는다.
- 1회 실행이다. 반복성은 재지 않았다.
- 비용(API 보고): 이번 웹 검색 실행 $5.539, 앞서 웹 검색을 끈 채 시작했다가 조건을 바꿔 멈춘 실행 $0.911. 응답을 받지 못한 3건은 과금 여부를 모른다. 실행 스크립트는 실행자 저장소 `.env`의 `OPENROUTER_API_KEY`를 읽는다(조 OpenRouter 키로 추정). 멈춘 실행의 답은 이 폴더에 없다.
