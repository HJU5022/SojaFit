# 50건 동결 전 자동 대조 기록 — 2026-11-02

이 문서는 사람 판정 전에 수행한 숫자·해시·근거 자동 대조의 당시 기록이다. 이후 하정운·김재훈의 검토와 합의를 거쳐 v1을 동결했다. 현재 사람 검수 결과는 [검토표](draft_50_review.md), 동결본은 [평가셋 안내](../dataset-guide.md)를 따른다. 아래의 빈칸·미확인 사항은 당시 상태다.

## 당시 결과

- 기준 커밋: main `c02d3ef`.
- 고유 문항 50건, 관련 25·비관련 25. 비관련은 범위 밖 6·대상 없음 7·속성 없음 6·기간 다름 6이다.
- 50건 모두 필수 정답 필드·NET 해시·연결 JSON의 대상 존재·정답 근거 유무를 확인했다.
- 관련 문항이 인용한 PDF 6개는 manifest의 SHA256과 모두 일치한다. 저장소 표본 3개와 제조사 원본에서 임시로 받은 3개를 사용했다. 새 PDF는 저장소에 넣지 않았다.
- PDF의 텍스트 레이어로 수치·행·주석을 대조했다. 회전 글자 추출 경고가 있어 모든 그림을 검증했다고 보지 않는다. G1804 5쪽 정전용량과 G2606 3쪽 서지 곡선은 렌더링해 확인했다.
- n06의 회로 인용에서 D3.C 넷 이름 `VCC`를 실제 NET의 `5V`로 정정했다. 동일품 정답과 사람 판정 이력은 바꾸지 않았다.
- 당시 `dataset_v1.jsonl`은 예시 2건이었고 `FROZEN.json`은 없었다. 이 검증에서는 생성하지 않았다(이후 2026-11-02 동결).

## 동결 전에 정할 것

1. **n01:** 입력은 TJ=25°C이고 H2104 1쪽 정격의 기본 조건은 TA=25°C다. 현재 정답은 추가 확인을 전제로 ROLE_SUFFICIENT를 쓰면서 NOT_VERIFIED도 허용한다. 질문을 보존한다면 최종 정답을 **NOT_VERIFIED**로 단일화할 것을 제안한다. `why`도 필수 조건을 모두 만족했다고 쓰지 않아야 한다. ROLE_SUFFICIENT를 유지하려면 질문의 TA 조건을 보완하고 두 사람이 변경된 문항에 다시 판정해야 한다. → 11-02 해결: NOT_VERIFIED로 바꾸고 하정운 O로 합의.
2. **n02:** IF=70mA, IFSM=100mA(t=1s)와 코일 150mA 수치는 맞다. 그러나 차단 펄스 폭·파형이 없어서 t=1s 정격 또는 8.3ms 곡선과 같은 조건이라고 확정할 수 없다. **NOT_VERIFIED**를 제안하며, 명백한 필수 조건 불충족으로 볼지 하정운과 김재훈의 합의가 필요하다. 현재 불충족 정답은 임의로 바꾸지 않았다. → 11-02 해결: NOT_VERIFIED로 바꾸고 하정운 O로 합의.
3. **부재 근거:** `tsc_datasheet_list.csv`와 전체 외부 코퍼스가 저장소에 없다. manifest는 문서 단위이며 모든 parts 토큰을 담지 않는다. unknown_entity 7건의 완전 일치 부재를 제목 검색만으로 검증했다고 할 수 없다. 1차 기록의 부재 판정을 유지하되 전체 품번 색인 대조는 미확인이다. 실측·USB 시험 자료 부재도 저장소 목록과 제공 파일 범위에서만 확인했다. → 동결 시점까지 미해결(전체 품번 색인 대조 없음).
4. **판정 기준:** 정답들이 인용한 `정답판정-기준표.md`는 저장소에 없다. 특히 1.25배·0.7 여유, 역할별 필수 조건은 검토표의 설명을 재확인했을 뿐 원문과 대조하지 못했다. 기준표 또는 합의한 규칙의 버전·해시를 동결 근거에 연결해야 한다. → 동결 시점까지 미해결(기준표는 저장소 밖).
5. **사람 판정:** [ADR 0003](../../docs/adr/0003-평가셋-v1을-50건으로-동결.md)은 “김재훈 2차 판정 … 두 판정이 다른 문항만 함께 다시 본 뒤 동결”로 정한다. 아래 의견을 검토한 실제 사람의 결론만 `human_2`에 기록한다. → 11-02 김재훈 2차 판정 기록. 숫자형 7건은 2차 사람 판정 없이 1차 사람 판정과 숫자 기계 대조로 동결.
6. **승격:** 위 사항을 해소한 뒤 50건을 `dataset_v1.jsonl`로 승격한다. 미확정 상태·옛 `review_flags`·초안 표시를 정리하고, 실제 검수 이력과 manifest 해시를 남긴다. 이후 `uv run python evals/freeze.py dataset_v1.jsonl`, `uv run python evals/freeze.py --check`, 동결 감시 테스트 순으로 실행한다. → 11-02 고정 키만 `dataset_v1.jsonl`로 옮겨 동결. `draft_50.jsonl`의 상태 표시는 정리하지 않고 이력으로 남김.

검색/답변 모델 평가와 점수 재측정은 실행하지 않았다. API 호출은 0회다. 이 결과는 검색 성능·실제 회로 동작·최종 사람 판정의 증거가 아니다. 동결 감시 테스트는 1개 통과했지만 FROZEN.json이 없는 상태의 통과이므로 동결 성공 증거가 아니다.
