# public

## 역할
- 넣는 것: Vite가 파일 이름을 유지한 채 웹 루트에서 제공해야 하는 화면 전용 정적 이미지.
- 넣지 않는 것: React·TypeScript 소스(`frontend/src/`), 빌드 산출물(`frontend/dist/`), 사용자 업로드, 비밀값, 서버 데이터와 판정 근거.
- 담당: 서비스·운영.

## 파일
- `PUBLIC.md` — 이 폴더 설명.
- `circuit-schematics/` — 검증된 공개 원본에서 고정한 데모 회로도 PNG 15개.
- `assets/` — Vite 개발 화면과 FastAPI 배포 화면이 `/assets`로 제공하는 브랜드 이미지. [ASSETS.md](assets/ASSETS.md)

첫 화면은 문구·CTA·실측3칸이며 수치는 모바일에서도 한 행이다. 실제 작업대 캡처3장은 사용 방법에서만 예시 데이터 표시와 함께 세로로 이어 보여주고 확대를 제공한다. 사용자 업로드나 실제 운영 분석 기록은 포함하지 않는다. 배경은 사용자가 선택한 기판 이미지를 사용한다.
