# tests

## 역할
- 넣는 것: 화면 순수 함수의 단위 시험(`*.test.ts`, `node --test`)과 브라우저 시험(`*.spec.ts`, Playwright).
- 넣지 않는 것: 화면 소스(`../src/`), 서버 판정 시험(`tests/` 루트), 비밀값.
- 담당: 서비스·운영.

## 실행
- 단위 시험: `npm test`. 서버·브라우저 없이 돈다(CI가 이 명령을 쓴다).
- 브라우저 시험: `npm run test:e2e`. 키 없는 데모 서버(`DEMO_MODE=1 DEMO_REPLAY=1`)가 떠 있어야 하고, 설치된 Google Chrome을 쓴다. 기본 주소 `http://localhost:8000`(개발 서버를 쓰면 `SOJAFIT_BASE_URL=http://localhost:5173`). 데모 사용자 A·B의 프로젝트·승인·견적·설정을 만들고 지우므로 운영에는 쓰지 않는다. CI에는 두지 않았다.

## 파일
- `TESTS.md` — 이 폴더 설명.
- `display.test.ts` — 긴 소수 반올림, 판정 기준식의 한국어 풀이, 답변 속 괄호 기준식·인용 번호 숨김, http(s) 링크·같은 출처 이미지만 허용, 입력칸 안내, 수량 검사·수량별 가격 조회 경로·예상 금액 줄.
- `stream.test.ts` — SSE 프레임 복원(바이트 단위로 쪼개진 한국어, 종료 이벤트 없는 연결 종료).
- `circuit.test.ts` — 프로젝트 연결에서 부품 목록과 핀·넷 뽑기, LED·표시기·비다이오드 부품이 이유와 함께 판정 대상에서 빠지는지.
- `demo.spec.ts` — 데모 로그인 → 검토 → 조건 재개 → 승인·견적 → 설정까지의 브라우저 흐름, 랜딩 이미지가 그림으로 받아지는지.
- `account.spec.ts` — 설정 저장·복원, 데모 A·B 계정 격리, 비관리자의 관리자 화면 차단, 첨부 넷리스트의 새 회로 버전.
