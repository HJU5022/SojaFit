# reference

## 역할
- 이 폴더: 여러 문서가 가리키는 참조 문서를 둡니다. 계약서, 용어집, 평가 준비 점검표입니다.
- 넣는 것: `<english-kebab>.md`. 한 번 쓰고 계속 찾아보는 문서.
- 넣지 않는 것: 과제 가이드가 이름을 정한 `../TOPIC.md`·`../GATES.md`, 조사·실측 기록(`../research/`), 기능 작업서(`../specs/`), 결정(`../adr/`), 기능의 정본(루트 `SPEC.md`).
- 담당: 평가·문서

## 파일
- `team-contract.md` — 요청 흐름, 담당별 수정 경로, 모듈 사이 함수 계약, 코드가 읽는 파일과 환경변수, 오프라인 규칙(옛 이름 `조원-계약서.md`)
- `glossary.md` — 용어집: 문서에서 쓰는 말(청크, dev · test 세트, Page Recall 등)과 예전에 쓴 말
- `evaluation-prep.md` — 배점·가산 항목별 준비 점검(기존 문서에 없는 평가 축·시장 근거·가산 준비 항목)
