# reference

## 역할
- 이 폴더: 여러 문서가 가리키는 참조 문서를 둡니다. 구조·계약 문서, 용어집, 평가 준비 점검표입니다.
- 넣는 것: `<english-kebab>.md`. 한 번 쓰고 계속 찾아보는 문서. 문서마다 첫머리 헤더(상태, 기준일, 기준 커밋, 정본 여부, 관련 문서)를 둡니다.
- 넣지 않는 것: 과제 가이드가 이름을 정한 `../TOPIC.md`·`../GATES.md`, 조사·실측 기록(`../research/`), 기능 작업서(`../specs/`), 결정(`../adr/`), 기능의 정본(루트 `SPEC.md`).
- 담당: 평가·문서

## 줄 번호
- 문서 안의 `파일:줄` 번호는 그 문서 머리의 기준 커밋 때의 것이다. 코드가 바뀌면 몇 줄씩 어긋나므로 함수 · 상수 이름으로 찾는다.
