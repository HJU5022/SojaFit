# docs

## 역할
- 이 폴더: 사람이 읽는 문서(과제 문서, 결정, 작업서, 조사, 제출물, 작업 기록)를 둡니다.
- 넣는 것: 이 폴더 바로 아래에는 과제 가이드가 이름을 정한 과정 문서(`TOPIC.md`, `GATES.md`)만 둡니다. 그 밖의 문서는 종류에 맞는 하위 폴더에 둡니다: 계약서·용어집·평가 준비 점검표는 `reference/`, 결정은 `adr/`, 기능 작업서와 승인된 실행 계획·설계 원문은 `specs/`, 사전 등록한 실험의 계약(과 그 문서에 함께 적은 결과)은 `experiments/`, 조사·실측 기록과 합의 전 제안, 길어서 따로 쓴 실험 결과 보고는 `research/`, 제출물은 `deliverables/`, 작업 기록은 `worklog/`, 지금 기준이 아닌 옛 문서는 `archive/`.
- 넣지 않는 것: 기능의 정본(루트 `SPEC.md`), 평가 리포트(루트 `EVAL_REPORT.md`), 저장소 지도(루트 `SOJAFIT.md`), 측정 원시 결과(`evals/results/`, `scripts/results/`).
- 담당: 평가·문서

## 파일
- `TOPIC.md` — 통과한 주제서(과제 가이드가 경로를 정함)
- `GATES.md` — 필수 게이트 G1~G7을 어디서 채우는지와 증거, 테스트를 일부러 깨뜨려 본 기록 표(과제 가이드가 경로를 정함)
- `assets/` — 문서에 넣는 구조도 이미지와 원본. [ASSETS.md](assets/ASSETS.md)
- `reference/` — 계약서·용어집·평가 준비 점검표. [REFERENCE.md](reference/REFERENCE.md)
- `adr/` — 조 결정 기록. [ADR.md](adr/ADR.md)
- `specs/` — 기능 작업서와 승인된 실행 계획 · 설계 원문. [SPECS.md](specs/SPECS.md)
- `experiments/` — 사전 등록한 실험의 계약과 결과. [EXPERIMENTS.md](experiments/EXPERIMENTS.md)
- `research/` — 조사·실측 기록과 합의 전 제안(주제 하위 폴더 `market/` · `mcp/` · `schematic/` · `db-redesign/` · `evidence/`). [RESEARCH.md](research/RESEARCH.md)
- `deliverables/` — 최종 제출 문서 양식. [DELIVERABLES.md](deliverables/DELIVERABLES.md)
- `worklog/` — 조원별 작업 기록. [WORKLOG.md](worklog/WORKLOG.md)
- `archive/` — 지금 기준이 아닌 옛 문서 보관(정본 아님). [ARCHIVE.md](archive/ARCHIVE.md)
