# docs

## 역할
- 이 폴더: 사람이 읽는 문서(과제 문서, 결정, 작업서, 조사, 제출물, 작업 기록)를 둡니다.
- 넣는 것: 이 폴더 바로 아래에는 과제 가이드가 이름을 정한 과정 문서(`TOPIC.md`, `GATES.md`)와 `evaluation-prep.md`, `조원-계약서.md`만 둡니다. 그 밖의 문서는 종류에 맞는 하위 폴더에 둡니다: 결정은 `adr/`, 기능 작업서는 `specs/`, 실험·평가 작업서는 `experiments/`, 조사·실측 기록과 합의 전 제안은 `research/`, 제출물은 `deliverables/`, 작업 기록은 `worklog/`.
- 넣지 않는 것: 기능의 정본(루트 `SPEC.md`), 평가 리포트(루트 `EVAL_REPORT.md`), 저장소 지도(루트 `SOJAFIT.md`), 측정 원시 결과(`evals/results/`, `scripts/results/`).
- 담당: 평가·문서

## 파일
- `TOPIC.md` — 통과한 주제서(과제 가이드가 경로를 정함)
- `GATES.md` — 필수 게이트 G1~G7을 어디서 채우는지와 증거, 테스트를 일부러 깨뜨려 본 기록 표(과제 가이드가 경로를 정함)
- `evaluation-prep.md` — 배점·가산 항목별 준비 점검(기존 문서에 없는 평가 축·시장 근거·가산 준비 항목)
- `조원-계약서.md` — 요청 흐름, 담당별 수정 경로, 모듈 사이 함수 계약, 코드가 읽는 파일과 환경변수, 오프라인 규칙
- `adr/` — 조 결정 기록. [ADR.md](adr/ADR.md)
- `specs/` — 기능 작업서. [SPECS.md](specs/SPECS.md)
- `experiments/` — 실험·평가 작업서. [EXPERIMENTS.md](experiments/EXPERIMENTS.md)
- `research/` — 조사·실측 기록과 합의 전 제안. [RESEARCH.md](research/RESEARCH.md)
- `deliverables/` — 최종 제출 문서 양식. [DELIVERABLES.md](deliverables/DELIVERABLES.md)
- `worklog/` — 조원별 작업 기록. [WORKLOG.md](worklog/WORKLOG.md)
