# 평가 정보 부족 기준과 50건 검수 초안

## Why

사용자 조건 부족과 문서 속성 부재를 구분해야 한다. h03 재분류 후 24/26을 맞추기 위해 관련 2건을 추가했던 52건 초안은 최종 50건으로 조정한다. 파일명의 52는 당시 작업서 이력으로 유지한다.

## Goal

- 본편 50건, 관련 25·비관련 25. 기존 52건에서 관련 n22·비관련 n13만 예비로 이관한다.
- 남는 50건의 질문·정답·근거·사람 판정 기록을 바꾸지 않는다. n01·n02·h03의 재검수 대상도 유지한다.
- Out of Scope: 정답 재판정·동결·공식 측정·코퍼스/저장 구현 변경.

## What

- n22는 단일 정전용량 조회인 추가 관련 문항으로 예비 이관한다. 온도·시험 조건을 함께 확인하는 n21은 유지한다.
- n13은 다른 품번 부재(unknown_entity) 조회와 유형이 겹쳐 예비 이관한다. 비관련 4유형과 회로 5종은 모두 유지한다.
- 52건 원본·검토표와 이관 두 문항의 전체 JSONL·사람 판정은 저장소 밖 인수인계 폴더에 보존한다. 본편 정답을 수량에 맞춰 바꾸지 않는다.
- 현재 사람 합의 39건·숫자형 기계 대조 7건·변경/추가 검수 대기 4건(n01·n02·h03·n21)을 구분한다. 이전 40/7/5와 52건 결과는 당시 스냅샷이다. 11-02 하정운 검수 뒤에는 43/7/0이다.

## How

- `evals/draft_50.jsonl`에서 draft52-n22·draft50-n13 행만 바이트 그대로 분리한다. ID를 다시 매기지 않는다.
- `DRAFT_50_REVIEW.md`에서 현재 구성을 50건으로 표시하고 예비 문항의 본편 검토란은 제거한다. 이전 판정 기록은 별도 사본에 보존한다.
- EVALS·SPEC·평가 리포트·ADR 0008과 지도를 같은 변경에서 맞춘다. 과거 원시 결과는 덮어쓰지 않는다.
- PR 설명에는 최종 변경·검증·남은 확인만 적고 작업 지시·허락 경위를 넣지 않는다.

## AC

- Given 52건, When 이관, Then 본편 50건(25/25)·예비 2건(1/1), 전체 고유 ID와 원문은 보존된다.
- Given 남은 50건, When 원본 대조, Then 각 행은 원본 바이트와 같고 비관련 네 유형·회로 다섯 종이 유지된다.
- Given 검수 상태, When 집계, Then 39/7/4이고 사람 O를 추가하거나 변경하지 않는다(11-02 하정운 검수 전 작업 기준).
- Given dataset_v1/FROZEN, When 전후 비교, Then 변경 없고 공식 동결·측정 완료를 주장하지 않는다.
