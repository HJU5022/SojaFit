# 제조사 데이터시트 원문 인용

## Why
내부 문서에서 다이오드의 정격을 확인하지 못했을 때 설계자가 답의 숫자를 제조사 PDF의 같은 품번 열에서 직접 대조할 수 있어야 한다.

## Goal
내부 코퍼스로 질문에 답할 수 있으면 Exa 호출은 0회다. 공식 원문에서 검증한 행을 2등급으로 사용한다. 적합한 공식 행을 채택하지 못하면 같은 품번의 공개 참고 링크를 3등급으로 조회한다. 문서·판정 에이전트는 실행당 공식 검색 1회, 참고 검색 1회의 예산을 공유한다. 외부 검색 슬롯이 이미 사용 중이거나 예산을 소진한 상태는 `no evidence`가 아니라 `budget_exhausted`/제한 상태다. 빈 검색 결과로 오인해 3등급으로 자동 전환하지 않는다.

## What
각 PDF 인용에는 `[W1]` 형식의 번호가 붙는다. 결과의 `evidence`에는 PDF 이름, 1부터 시작하는 페이지, 표 제목, 행 이름, 원문 페이지 링크, `evidence_grade=2`, 원본 바이트의 `source_sha256`이 들어간다. 검색 결과에 공식 링크만 있거나 표의 품번·수치가 불명확하면 기존 부분 답변·근거 부족 처리로 돌아간다.

## How
실서비스 설정에서 `DEMO_MODE=0`, `EXA_WEB_SEARCH_ENABLED=1`, 서버의 `EXA_API_KEY`와 기존 OpenRouter 설정을 사용한다. 부품명과 허용 검색어로 Exa를 호출하고 응답 후보 5개 중 TSC·Infineon 공식 데이터시트 PDF를 최대 2개 확인한다. 같은 제조사의 허용 경로로 한 번 이동할 수 있다. 한 파일 12 MiB, 첫 32쪽, 파서 실행 12초로 제한한다. 품번 열의 숫자를 원문 셀과 대조한다. Infineon의 공통 역전압 행은 첫 쪽 품번 목록, 정격표 행, 심볼과 숫자 셀까지 확인한다.

문서 질문은 모델이 선택한 원문 행에서 수치·단위·품번을 그대로 답한다. 요청에 판본이 여러 개 포함되면 품번별로 요청된 판본과 데이터시트 행을 매핑한다. 전체 후보 집합에 판본이 하나라도 있다는 것만으로는 충분하지 않으며, 해당 품번의 정확한 판본을 확인하지 못한 값은 채택하지 않는다. 대체 후보 판정에서는 내부 사양에 빠진 반복 피크 역전압(VRRM)만 공식 최대정격 행에서 보충한다. 같은 품번의 다른 제조사 문서나 일반 역전압(VR)을 VRRM으로 쓰지 않는다. 나머지 판정 조건이 부족하면 해당 조건은 확인할 수 없다고 표시한다. PDF와 추출 원문은 DB에 적재하지 않는다. 응답과 대화 재조회에는 동일한 인용 번호와 출처를 제공한다.

## AC
- 외부 행은 모델이 인용 번호로 선택한다. 서버가 해당 행의 품번·값·단위와 시험 조건을 넣어 답변을 만들고, 최종 문장을 같은 행에서 만든 문장의 해시와 대조한다. 품번·값·단위를 바꾼 외부 근거 문장은 거절한다.
- 내부 근거가 충분한 질문이면 외부 검색 없이 답한다.
- 공식 제조사 표에 같은 계열의 두 품번이 있으면 요청한 품번 열의 값과 단위만 인용한다. 정확한 품번을 확인할 수 없으면 해당 값은 인용하지 않는다.
- 공식 PDF의 페이지와 행을 확인해 답했다면 응답과 재조회 모두 같은 문서·페이지·표·행을 표시한다.
- 3등급 검색에서는 제목 또는 URL에서 요청 품번을 확인한다. 최종 응답과 대화 재조회에 `[R1]` 형식의 번호, `evidence_grade=3`, HTTPS 링크를 ‘미검증 참고 정보’로 표시한다. 웹 본문 다운로드와 페이지 문구를 이용한 수치 판정은 수행하지 않는다.
- 사용자가 판본을 지정하면 질문·사용 조건에서 판본을 추출하고 데이터시트 행과 검사 결과까지 대조한다. 맞는 문서를 확인하지 못하면 다른 판본의 정격값으로 대체하지 않는다.
- 외부 조회 슬롯이 점유·소진되어 실행되지 않은 경우는 공식 문서 부재로 판정하지 않는다. 공식 검색의 실제 무결과·후보 탈락·행/품번 불일치처럼 근거가 없음을 확인한 경우에만 3등급 참고 검색으로 넘어간다. 요청당 상한(공식 1회 + 참고 1회)은 유지한다.

- 사용자가 정확한 발주 품번을 요구하면 현재 질문의 품번을 내부 재검색과 외부 조회에도 유지한다. 사용 조건·이전 대화의 다른 품번이나 유사 품번의 정격으로 대신 답하지 않는다.
- Infineon 공식 문서 경로의 데이터시트 이름 표시는 `datasheet`와 `ds`를 모두 인정한다. 채택하는 수치는 계속 원문에서 품번과 표 행을 확인한다.

- 문서명과 제목의 정확 품번·계열 관련성으로 다운로드 순서를 정하되, 최종 채택은 원문 표의 정확 품번으로 검증한다. 품번이 데이터 행에 있는 표와 실제 셀 범위가 여러 행을 덮는 병합 표도 지원한다. 공유 조건은 PDF 셀의 물리적 범위를 확인한 경우에만 연결한다.
- 상세 trr 측정조건 요청에서 내부 청크가 IF/IR/Irr를 모두 보존하지 못하면 공식 원문 행을 조회한다. 그 행을 채택하면 내부의 부정확한 조건 부재 문장을 대체하고 코드가 검증한 값·단위·조건 문장으로 인용한다.
- 상세 역회복 측정 기준은 동일 PDF에서 해당 표와 연결되는 캡션 아래 원본 그림 1개를 추가로 읽을 수 있다. PNG는 메모리에서 최대 1600px·512KiB로 제한하고 기존 `node_chat`의 같은 모델에 전달한다. 원본 이미지는 대화·DB·프롬프트 추적에 저장하지 않는다. 판독된 순방향 전류·역방향 피크·회복 전류와 측정 화살표의 끝점을 `backend/judge/pdf_claims.py`에서 표의 IF/IR/Irr와 대조한다. 판독 불가나 불일치이면 그림 설명을 채택하지 않는다. 표와 그림은 각자의 PDF 페이지에 별도 W 인용을 부여한다. 이 해석은 실제 코일 실측이나 교체 적합성의 보장이 아니다.
