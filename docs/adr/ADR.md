# adr

## 역할
- 이 폴더: 조의 결정 기록(ADR)을 둡니다. 결정 하나에 파일 하나입니다.
- 넣는 것: `NNNN-한국어-제목.md`(0001부터). 본문은 날짜, 상태(채택·보류·대체됨), 근거 줄과 `## 결정`, `## 이유`. 배경·검토한 대안·결과는 아는 것만 적습니다.
- 넣지 않는 것: 지금 기능의 정본(루트 `SPEC.md`), 개인 결정.
- 담당: 결정을 낸 담당

## 규칙
바뀐 결정은 지우지 않고 상태를 `대체됨 → NNNN`으로 고칩니다.
