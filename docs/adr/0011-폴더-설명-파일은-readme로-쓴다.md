# 0011 폴더 설명 파일은 README.md로 쓴다

- 날짜: 2026-11-02
- 상태: 채택
- 근거: 조장 하정운 결정(11-02)

## 결정
- 폴더 설명 파일은 그 폴더의 `README.md`로 쓴다(예: `backend/README.md`). 적는 내용(역할, 넣는 것, 넣지 않는 것, 담당, 파일)과 두 단계까지만 두는 규칙은 [0001](0001-디렉토리-구조와-문서-위계.md) 그대로다.
- [0002](0002-폴더-설명-파일-이름-대문자.md)에서 바뀌는 것은 폴더 설명 파일 이름뿐이다. 저장소 지도 `SOJAFIT.md`와 루트 대표 문서의 이름은 그대로다.

## 이유
- GitHub은 폴더를 열면 그 폴더의 `README.md`를 파일 목록 아래에 보여 준다. `<대문자 폴더명>.md`는 목록에서 직접 눌러야 보인다.
- 폴더마다 `README.md`를 두는 것이 널리 쓰는 관행이라, 처음 보는 사람이 이 저장소만의 이름 규칙을 따로 익히지 않아도 된다.
- `README.md`도 대문자라 0002의 이유(같은 폴더의 코드·자료 파일과 이름만으로 구분)는 그대로 지켜진다.
