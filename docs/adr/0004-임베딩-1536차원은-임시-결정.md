# 0004 임베딩 모델과 벡터 차원(1536)은 임시 결정으로 둔다

- 날짜: 2026-11-01
- 상태: 채택(임시)
- 근거: 조장 하정운 결정(11-01), `db/002_rag_corpus.sql`, `evals/preregister.md` #1·#2·#7·#8, PR #17 오세창 검수 의견
- 일부 바뀜: 본평가 후보와 순서는 `SPEC.md` 1절과 `EVAL_REPORT.md` 「다음 본평가」를 따른다(11-02). `text-embedding-3-small`·`vector(1536)` 임시 결정은 그대로다

## 결정
- 검색 임베딩은 `text-embedding-3-small`(1536차원)을 쓰고, `chunk_embeddings.embedding`을 `vector(1536)`으로 만든다. 이것은 본평가 전 임시 결정이다.
- 모델은 v1 동결 뒤 사전 등록 #1(`KURE-v1`)·#2(`Qwen3-Embedding-0.6B`) 본평가로 확정한다. 다른 차원의 모델로 바꾸면 새 Migration으로 벡터 열을 바꾸고 임베딩을 다시 넣는다.

## 이유
- 검색 베이스라인을 재려면 지금 쓸 벡터 표가 필요하고, 1,360건 임베딩이 이미 있어 추가 비용 없이 넣을 수 있었다.
- 11-01 예비 실험(초안 19문항)에서 두 로컬 모델은 정확 검색 하이브리드 MRR이 0.895로 `text-embedding-3-small`(0.921)보다 높지 않았지만, 동결 평가셋으로 다시 재기 전이라 확정하지 않는다.
