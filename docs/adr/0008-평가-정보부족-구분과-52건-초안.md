# 0008 평가 정보 부족을 구분하고 52건 초안으로 확장한다

- 날짜: 2026-11-02
- 상태: 분류 기준 채택. 52건 수량 계획은 아래 후속 결정으로 50건 조정. 변경 답안 재검수·합의 및 n21의 하정운 검수 대기
- 근거: 김재훈의 대화 지시 "기준 확정하고, 두 건을 추가해보자", `evals/DRAFT_50_REVIEW.md`의 n01·n02·h03 재훈 변경 의견

## 결정

- `kind`와 대체 판정 5종을 별도 축으로 둔다. 후보 정격·판정 근거가 있으나 사용자의 동작 조건이 부족하면 relevant + NOT_VERIFIED로 둔다. 핵심 요청에 필요한 문서 속성이 없으면 irrelevant / missing_attribute다. 자세한 기준의 정본은 `evals/EVALS.md`다.
- n01·n02는 NOT_VERIFIED, h03은 missing_attribute로 현재 JSONL 초안을 바꾸고, 이전 정답과 사람 판정 이력을 보존한다. 변경 답안은 하정운의 재검수와 이견 합의 전까지 동결하지 않는다.
- h03 변경 후 기존 50건이 24/26이 되므로, 기존 ID·질문은 모두 보존하고 관련 문항 n21·n22를 추가해 52건(26/26) 초안으로 확장한다. 새 문항은 출제·근거 확인 AI를 분리하고 두 사람 검수는 별도로 받는다.
- 파일명의 50은 최초 초안 건수로 남겨 기존 링크를 유지한다. ADR 0003의 50건 수량 계획을 이 초안 계획으로 대체하되, 두 사람 검수·이견 합의·동결 후 원문 보존 원칙은 유지한다. 실제 동결은 아직 하지 않았다.

## 이유

- 사용자에게 추가 조건을 받으면 적용을 검토할 수 있는 경우와, 코퍼스에 요청한 속성 자체가 없는 경우를 같은 거절로 처리하지 않기 위해서다.
- 비관련 한 건을 삭제·재분류해 비율을 맞추는 대안 대신, 기존 질문을 보존하고 두 문항을 추가하는 방식을 사용자가 선택했다. 관련 의도만으로 정답을 강제하지 않고 실제 PDF 근거를 확인한다.

## 2026-11-02 후속 결정: 본편 50건

- 최종 50건 요청에 따라 n22(관련)·n13(비관련)을 예비로 이관해 25/25를 유지한다. 기존 52건과 이관 두 문항의 질문·정답·근거·사람 판정은 저장소 밖에 보존한다.
- n22는 추가 단일 속성 조회, n13은 다른 unknown_entity 정격 조회와 겹치는 문항이다. 남은 질문이나 판정을 수량에 맞춰 고치지 않는다. n01·n02·h03 변경 의견은 검토 대상으로 유지한다.
- 현재 본편은 합의 39건·기계 대조 7건·재검수 대기 4건이며 공식 동결은 하지 않았다. 위 52건 결정은 변경 이력으로 남긴다.
