# 0007 코퍼스를 기존(동결)과 증분으로 나누고, 평가는 기존만으로 잰다

- 날짜: 2026-11-02
- 상태: 채택
- 근거: 조장 결정(11-02), 3차 가이드 v5 가산점 표(증분 수집과 정해진 시각 실행)와 평가셋 규칙, Infineon 약관·robots.txt 확인(11-02)

## 결정
- 기존 코퍼스는 TSC 1,360건(`corpus_version` `tsc-diode-2026-11-01`)으로 동결한다. 증분 코퍼스는 정해진 시각에 받은 새 문서·새 개정판과, 질문할 때 실시간으로 받은 TSC 문서다. 평가셋 v1의 `corpus_version` 표기("TSC 다이오드 데이터시트 1,360건(2026-11-01 수집)" 49건, n21의 manifest sha256 1건)도 이 기존 코퍼스를 가리킨다.
- 증분 문서는 검증 관문(sha256 기록, PDF 확인, 파싱 오류 0, pdfplumber 대조)을 통과한 것만 검색에 넣는다. 실패한 문서는 격리하고 알린다. 새 개정판이 들어오면 옛판은 `retired_at`으로 내린다.
- 평가(G5)는 기존 코퍼스만, 실시간 조회를 끈 채로 잰다. 서비스는 두 덩어리를 다 검색한다. 증분이 들어온 뒤에는 서비스 설정으로 같은 평가셋을 한 번 더 재서 달라진 문항 목록을 남긴다.
- 회사별로 TSC는 코퍼스와 실시간 조회를 쓰고, 재배포나 자동 수집을 금지하는 회사는 링크만 보여 준다. Infineon은 질문할 때 받아 보여 주는 것까지는 약관상 허용되지만, 파싱한 글을 저장해 검색에 쓸지는 정하지 않았다.

## 이유
- 평가셋을 동결한 뒤 코퍼스가 바뀌면 정답이 달라진다. 비관련 문항 중 다른 개정판 6건은, 증분이 그 개정판을 받으면 서비스는 맞게 답해도 평가에서는 틀린다.
- 증분 수집 가산점은 새 문서만 받아 추가·갱신을 반영하고, 중복 실행을 막고, 정해진 시각 실행 기록과 실패 알림이 있어야 인정된다.
- Infineon 약관은 정보·비상업 목적의 내려받기·복제·표시·배포를 비수정·저작권 표시 유지·출처 표기 조건으로 허락하고, robots.txt는 데이터시트 경로(`/assets/row/public/*`)를 허용한다. 저장·캐시 조항은 없고, 이용 허가가 끝나면 받은 콘텐츠를 지워야 한다. AWS WAF가 일부 기본 요청 이름(curl, python-requests)을 막는다.
