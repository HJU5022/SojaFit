# 0010 그래프 LLM은 `claude-haiku-5.5`로 시작하고, 측정 결과로 바꿀 수 있게 둔다

- 날짜: 2026-11-02
- 상태: 채택(임시)
- 근거: 조장 결정(11-02), 조장 로컬 10문항 비교 시험(11-02), OpenRouter 모델 목록 가격 조회(11-02), 강의 2주 `config.json`
- 일부 바뀜(11-05): "LLM 노드는 Haiku 하나"는 노드별 모델(Supervisor Sonnet · 그 밖 Haiku · 채점 Luna)로 바뀌었다 → [ADR 0014](0014-supervisor는-sonnet-서브에이전트는-haiku-채점은-luna.md).

## 결정
- 그래프의 LLM 노드는 OpenRouter `anthropic/claude-haiku-5.5` 하나로 시작한다. 모델 이름은 환경변수 `LLM_MODEL` 한 곳에서 바꾼다.
- 줄기(D4) 기준 점수를 잰 뒤 가지 실험과 평가셋 v2 측정 결과로 바꿀 수 있다. 노드별 모델 분리는 D5 구조 분리와 겹치지 않게 그 뒤에 한다. `path`로 실패를 노드별로 세어 가장 많은 노드 하나씩, `evals/guides/preregister.md`에 먼저 등록하고 바꾼다.
- 개발 중 반복 테스트는 같은 모델을 구독 CLI(`claude -p --model haiku`)로 돌릴 수 있다(`LLM_PROVIDER=claude_cli`). 결정에 쓰는 측정은 OpenRouter로 재고, 결과에 공급자·모델을 남긴다.
- 답변 평가는 규칙 채점을 먼저 하고, LLM 채점기는 생성과 다른 회사 모델 하나로 둔다. 채점 모델은 답 채점기를 만들 때 정한다(`evals/guides/dataset-guide.md`).

## 이유
- 평가셋 v1 10문항(관련 5·비관련 5)에 같은 근거·같은 프롬프트를 넣은 비교에서 `claude-haiku-5.5`와 `claude-sonnet-5.5`는 JSON 형식 10/10, 없는 근거 인용 0건, 비관련 5문항 거절 5/5로 같았다. 관련 문항에서 틀린 곳은 두 모델이 같은 근거 누락(넷리스트를 한 단계만 넣음, BM25 상위 5개에 품번별 정격 행이 빠짐) 때문이었다.
- 구독 CLI와 OpenRouter 양쪽에서 같은 모델로 돌릴 수 있어, 개발 중 다듬은 프롬프트와 측정하는 모델이 같다.
- 가격이 백만 토큰당 입력 0.10·출력 0.50달러로, 강의 기본 모델 `openai/gpt-4o-mini`(0.15·0.60)보다 낮다.

## 결과
- 강의 `config.json`의 기본 모델과 다르다. 그래프 구조와 노드는 강의 2주 20강을 따르고 모델 값만 다르다.
- 팀 OpenRouter 키로 실제 호출은 아직 확인하지 않았다. D4 전에 일반 응답과 구조화 출력을 한 번 확인한다.
- 비교는 10문항 한 번 실행이라 모델 품질의 확정 근거가 아니다.
