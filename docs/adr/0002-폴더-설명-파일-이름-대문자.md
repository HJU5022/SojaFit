# 0002 폴더 설명 파일과 저장소 지도의 이름을 대문자로 쓴다

- 날짜: 2026-10-30
- 상태: 채택
- 근거: 조장 하정운 결정(10-30)
- 일부 바뀜: 폴더 설명 파일 이름은 [0011](0011-폴더-설명-파일은-readme로-쓴다.md)에서 `README.md`로 바뀌었다

## 결정
- 폴더 설명 파일은 `<대문자 폴더명>.md`로 쓴다(예: `backend/BACKEND.md`). 저장소 지도는 `SOJAFIT.md`로 쓴다.
- 대문자는 루트 대표 문서(`README.md`, `SOJAFIT.md`, `SPEC.md`, `AGENTS.md`, `CLAUDE.md`, `EVAL_REPORT.md`)와 폴더 설명 파일에만 쓴다. 그 밖의 파일 이름은 대소문자를 가리지 않는다.
- [0001](0001-디렉토리-구조와-문서-위계.md)에서 바뀌는 것은 파일 이름뿐이다. 폴더마다 설명 파일 하나를 두는 구조와 나머지 결정은 그대로다.

## 이유
- 폴더 설명 파일은 에이전트가 `SOJAFIT.md`에서 시작해 필요한 폴더만 따라가게 하는 지도다. 이름이 대문자면 같은 폴더의 코드·자료 파일과 이름만으로 구분된다.
