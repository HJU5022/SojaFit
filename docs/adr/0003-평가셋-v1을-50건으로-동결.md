# 0003 평가셋 v1을 50건으로 동결한다

- 날짜: 2026-11-01
- 상태: 수량 계획 대체됨 → [0008](0008-평가-정보부족-구분과-52건-초안.md). 두 사람 검수·이견 합의 원칙은 유지. 실제 동결은 11-02에 했고(0008 후속 결정), 숫자형 7건(e03·e05·e08·m03·m07·n03·n05)은 2차 사람 판정 없이 1차 사람 판정과 숫자 기계 대조로 동결했다
- 근거: 조장 하정운 결정(11-01), `evals/draft_50.jsonl`, `evals/EVALS.md` 동결 계획, PR #15 오세창 검수 의견

## 결정
- 11-03에 동결하는 v1은 30건이 아니라 50건(관련 25, 비관련 25)으로 한다. 기존 30건(관련 17, 비관련 13)에 20건(관련 8, 비관련 12)을 더했다.
- 정답은 Codex 초안 → 하정운 1차 판정 → 김재훈 2차 판정 순서로 정하고, 두 판정이 다른 문항만 함께 다시 본 뒤 동결한다.
- v2(11-06)는 v1 50건을 그대로 두고 문항을 더할 때만 다시 동결한다. 후보 찾기 문항(주제서 질문 ③형) 20건은 v2 추가분으로 둔다.

## 이유
- 30건은 관련 17, 비관련 13이라 반반이 맞지 않았고, 최종 평가셋은 50건 이상·관련과 비관련 반반이어야 한다(`evals/EVALS.md`). 20건을 더하면 v1에서 바로 50건 반반이 되어 v2를 기다리지 않아도 된다.
- v1은 검색이 데이터시트를 잘 찾는지 재는 기준이라 지금 50건으로 충분하다. 후보 찾기는 에이전트(D4~D5)가 생겨야 답할 수 있어 v2에 넣는다.
