# 0006 판정은 문서 근거가 있을 때만 내고, 근거가 없어도 대화는 이어 간다

- 날짜: 2026-11-02
- 상태: 채택
- 근거: 조장 하정운 결정(11-02), 강사 답변(11-02, 조장 전달), 3차 가이드 v5 7쪽·16쪽·17쪽·25쪽

## 결정
- 판정 5종은 문서 근거(쪽·표·행)가 있을 때만 낸다. 근거가 없으면 "문서로 확인 안 됨"으로 판정하되, 대화를 끊지 않고 다음 방향을 준다(`SPEC.md` 2절 "근거가 없을 때").
- 근거로 인정하는 것은 코퍼스 데이터시트와, 공식 사이트에서 받아 검증 관문을 통과한 데이터시트다. 그 밖의 웹 글과 LLM이 아는 내용은 판정 근거로 쓰지 않는다.
- 후보는 대체 조건으로 코퍼스에서 찾은 품번과 사용자가 넣은 품번을 둘 다 받는다(사용자 흐름 5단계).

## 이유
- "확인할 수 없다"에서 대화가 끝나면 사용자는 다음에 할 일이 없다. 대체 조건은 회로 역할에서 정하므로, 원래 부품의 데이터시트가 없어도 조건을 만족하는 후보는 찾을 수 있다.
- 가이드는 답하는 일의 예로 근거를 붙인 질의응답과 되묻기를 들고, 근거가 부족하면 거절하라고 한다(7쪽). 비관련 질문의 정답은 근거가 없어 답할 수 없다는 거절이고(16쪽, 25쪽), 환각 위험은 답이 없는데 답한 경우다(17쪽).
- 강사는 코퍼스에 없어도 사용자 흐름상 답은 나와야 하고, TSC에서 실시간으로 받은 PDF와 믿을 만한 사이트의 자료는 근거로 인정한다고 답했다.
