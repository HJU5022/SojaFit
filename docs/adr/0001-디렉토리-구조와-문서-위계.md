# 0001 디렉토리 구조와 문서 위계

- 날짜: 2026-10-29
- 상태: 채택
- 근거: 조장 하정운 결정(10-29)

## 결정
- 루트에 대표 문서 `README.md`와 저장소 지도 `SojaFit.md`를 둔다. 기능의 정본은 루트 `SPEC.md` 하나다.
- 폴더마다 `<폴더명>.md`에 역할, 넣는 것, 넣지 않는 것, 담당, 파일을 적는다. 두 단계까지만 두고, 원본·결과물만 담는 폴더와 `.github/`에는 두지 않는다.
- 강사 스캐폴드의 고정 경로(`backend/` 패키지, 루트 `tests/`, `evals/`, `db/`, 루트 빌드 파일)는 옮기지 않는다.
- 폴더 하나에 담당 하나를 둔다. `backend/judge/`·`backend/graph/`는 에이전트, `backend/rag/`·`data/corpus/`는 검색·데이터, `backend/services/`·`backend/web/`·`db/`·Docker·CI는 서비스·운영, `evals/`·`docs/`는 평가·문서다.
- 숫자 비교와 단위 비교는 `backend/judge/`에서만 하고, LLM·임베딩 호출은 `backend/services/llm.py` 한 곳에서만 한다.
- 데모 모드 응답(`data/demo/`)에는 실제 API 응답 원본을 넣지 않는다.
- 조 결정은 `docs/adr/`에 0001부터 기록한다.
- 제출 문서의 평가 용어는 가이드 용어(사람 판정, 판정 기준)를 쓰고, 시스템이 내는 5종은 "대체 판정"이라 부른다.

## 이유
- 고정 경로를 옮기면 import가 깨지거나, 테스트가 가정한 위치가 바뀌어 동결 감시가 동작하지 않는다.
- 폴더 지도를 한 곳(`SojaFit.md`)에만 두면 README와 지도가 서로 어긋나지 않는다.
- 폴더마다 담당이 하나면 4명이 병렬로 일해도 같은 파일을 동시에 고치는 일이 줄어든다.
- 가이드는 평가 리포트에 판정 기준을 적으라고 한다.
