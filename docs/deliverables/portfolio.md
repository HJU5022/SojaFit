## 양식

복사한 파일은 아래 절을 이 순서와 이름으로 둔다. 제출용 A4 1장 PDF는 같은 구조로 뽑는다.

| 절 | 쓸 내용 |
|---|---|
| 머리(제목 아래 2줄) | **역할 한 줄** \| 프로젝트 · 기간. 다음 줄에 저장소 링크 · 배포 주소 위치(평가용 계정은 적지 않는다) |
| `## 문제` | 누구의 어떤 문제를 어떤 근거 기반 에이전트로 푸는가(조원 공통 문장) |
| `## 내가 맡은 것` | 맡은 축과 내가 만든 것, 3 ~ 4줄 |
| `## 핵심 성과` | 숫자 카드 3개: 3열 표(머리 = 무엇, 첫 행 = 굵은 숫자, 둘째 행 = 조건과 EVAL_REPORT 절). 이어서 `그 밖의 결과` 표에 LangGraph · 멀티 에이전트 · 평가 · 관측 수치 |
| `## 내가 내린 판단` | 버리거나 채택한 것과 이유. 버린 시도를 포함한다 |
| `## 기술` | 실제로 쓴 기술만 한 줄 |
| `## 근거` | 작업 기록 · 평가 리포트 링크(PR 번호를 나열하지 않는다) |
