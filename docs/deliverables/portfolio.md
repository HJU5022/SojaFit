## 양식

복사한 파일은 아래 다섯 절을 이 순서와 이름으로 둔다.

| 절 | 쓸 내용 |
|---|---|
| `## 프로젝트 한 줄` | 누구의 어떤 업무를 어떤 근거 기반 에이전트로 돕는가 |
| `## 내가 맡은 부분` | 표(항목, 내용): 맡은 축 / 내가 만든 것 / 내 커밋과 PR 링크 |
| `## 숫자로 보이는 결과` | 수치와 근거 경로. 예: 자체 평가셋 기준 지표의 전후. 수치는 `EVAL_REPORT.md`의 값 |
| `## 내가 내린 판단과 그 이유` | 버리거나 채택한 것과 이유. 버린 시도를 포함한다 |
| `## 배포 주소와 저장소` | 배포 주소(`README.md` 맨 위 표)와 저장소 주소 |
