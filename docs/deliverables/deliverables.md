# deliverables

## 역할
- 이 폴더: 최종 제출물 중 문서와 자료를 둡니다.
- 넣는 것: AI 코딩 도구 사용 기록, 실패 사례 분석, 포트폴리오, 발표 자료, Langfuse 대시보드 스크린샷 3장 이상(`langfuse/`).
- 넣지 않는 것: 평가 리포트(루트 `EVAL_REPORT.md`), 게이트 증거(`docs/GATES.md`), 시연 영상과 배포 주소(README 맨 위에 링크).
- 담당: 평가·문서
