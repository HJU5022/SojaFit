# deliverables

## 역할
- 이 폴더: 최종 제출물 중 문서와 자료를 둡니다.
- 넣는 것: AI 코딩 도구 사용 기록, 실패 사례 분석, 포트폴리오, 발표 자료, Langfuse 대시보드 스크린샷 3장 이상(`langfuse/`).
- 넣지 않는 것: 평가 리포트(루트 `EVAL_REPORT.md`), 게이트 증거(`docs/GATES.md`), 시연 영상과 배포 주소(README 맨 위에 링크).
- 담당: 평가·문서

## 파일
- `ai_tools_log.md` — AI 코딩 도구 사용 기록
- `failure_analysis.md` — 실패 사례 분석
- `portfolio.md` — 포트폴리오 1장

## 제출 전 추가 확인

- [ ] Langfuse 스크린샷에는 트레이스 상세 화면 1장 이상을 포함한다.
- [ ] AI 도구 사용 기록은 1장으로 정리하고, 실패 분석에는 원인·시도·결과·한계를 남긴다.
- [ ] 신뢰 경계 설명 1장과 인젝션·출처 유출 시험 전후 결과를 평가 리포트 6장에 포함한다.
- [ ] README에 최종 코드 SHA·설정/이미지·코퍼스 버전을 연결하고, 깨끗한 환경에서 키 없는 compose 기동 시간을 기록한다.
- [ ] 발표일까지 배포를 유지하고 제출 링크·최종 제출 경로·발표 시각을 확인한다.
