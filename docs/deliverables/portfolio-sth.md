## 내가 내린 판단과 그 이유

- **방어율이라고 부르지 않았다**: 사례당 5회 관찰이라 자동 분류와 사람 판정을 나눠 적었다.
- **C2를 "항상 종합 노드 호출"로 고치는 안을 버렸다**: 문서 보고 `ok`는 부품이 맞다는 뜻이 아니어서, 판정 답은 코드 판정표만 내는 쪽을 제안했다.
- **기억은 자동으로 지우지 않았다**: 삭제는 기억 사본과 이후 참조만 막고 대화 · 승인 원본은 남긴다.
- **운영 백업을 우회하지 않았다**: 전체 덤프가 막히자 데이터 없는 구조 백업으로 바꾸고 로컬에서 DB 변경을 먼저 리허설했다.
