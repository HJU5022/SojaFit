## 내가 내린 판단과 그 이유

- **방어율이라고 부르지 않았다**: 사례당 5회 · 버전당 1회 관찰이라 자동 분류와 사람 판정을 나눠 적었다(EVAL 6장, `docs/research/injection-results.md` 1.1절).
- **C2를 "항상 종합 노드 호출"이나 "보고 실패 처리"로 고치는 안을 버렸다**: 문서 보고 `ok`는 부품이 맞다는 뜻이 아니라서, 판정 근거로 판정표 문장만 만들고 판정 답에 문서 권고를 붙이지 않는 쪽을 제안했다(`docs/worklog/sth.md` 1224행).
- **기억은 자동으로 지우지 않았다**: 삭제는 Store 사본과 이후 참조를 막는 것이고 대화 · 승인 원본은 남긴다. 정정은 원본을 덮지 않는 메모로 둔다(`docs/worklog/sth.md` 1293행).
- **운영 백업을 우회하지 않았다**: 사용자 데이터 전체 덤프가 자동 승인 검토에서 거절되자, 데이터 없는 구조 백업으로 바꾸고 로컬 PG17에서 031을 먼저 리허설했다(`docs/worklog/sth.md` 2402행).
- **관측 코드를 새로 만들지 않았다**: 별도 추적 모듈 대신 기존 `langfuse_prompts.py`에 내용 없는 단계 기록을 더했다(`docs/worklog/sth.md` 1294행).
