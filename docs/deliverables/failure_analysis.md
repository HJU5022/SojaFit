## 1. 한 줄 요약

품번 없는 조건형 검색은 정답 쪽이 후보 50 밖에 남고, 표 주석이 행에 안 붙는 표(약 216)는 행 단위 조건을 빠뜨리며, 한때는 코드 판정은 불충족인데 설명 글이 “써도 된다”고 나가던 충돌이 있었다.

## 3. 원인을 어떻게 찾았나

- **검색:** R1 단계별 결과의 `outside_candidates` / `below_top_k`와 EVAL_REPORT 5장 유형 1~5. 품번 필터를 끄면 Page Recall이 떨어지는 #24 대조.
- **청킹:** ADR 0015 알려진 결함 → v4h로 Notes 부착. 11-09 점검에서 216=THERMAL 122+두쪽 61+기타 32+오탐 1(원장만, 원시 미이관). `table_suspects` 89는 파서 불일치라 다른 집합.
- **판정·답 충돌:** §6 C2 실측 → `supervisor._judgement_reply`가 판정 보고가 있으면 코드 판정표만 내게 함. D9 `run_claim_consistency` 재확인에서 사용 권고 0(`evals/results/threads/claim_consistency_d9_recheck_2026-11-12.json`).
- **partial 재검색:** 사전 등록 #49 · v3-20 실패 트레이스에서 검색어가 주문 정보에만 묶인 것을 확인.
