## 정상 경로 (~110초)

보여주는 것: 로그인 → 회로 → 판정 질문 → 조건 질문 정지 → 재개 → 승인 → 견적.

| 초 | 화면 | 말·동작 |
|---:|---|---|
| 0–8 | `/health` 또는 로그인 | “배포(또는 로컬)에서 로그인한다.” |
| 8–25 | 작업대 · 프로젝트 | ATtiny85 Time Switch · 대상 **D1**. (로컬이면 데모 회로로 시작) |
| 25–45 | 질문 전송 | v3-01형: D1을 1N4007G로 바꿔도 되는지. 조건 질문(`requires_input`)에서 멈춤을 보여 준다 |
| 45–70 | 재개 | 허용 전압강하 등 기록/준비한 답을 넣고 재개 → 판정표·쪽·표·행 인용 |
| 70–95 | 승인 · 견적 | 후보 승인 201 · 같은 승인 다시 409 · 견적 저장 |
| 95–110 | (선택) 다른 창 B | B로 들어가면 A 프로젝트·대화가 안 보임(격리). 시간 없으면 생략 |
