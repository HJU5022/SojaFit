- **사양 표 DB 경로를 버렸다**(ADR 0016): 카드 값 읽기·코드 비교로 충분했고, 표 적재 경로는 유지비가 컸다.

- **v3를 새로 동결**(ADR 0015): v2·청킹 결함이 섞인 점수를 쓰지 않으려고 평가셋·청커를 같이 갈았다.
