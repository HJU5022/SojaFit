# 임베딩 × 검색 방식 격자 본평가 (2026-11-02)

확인일: 2026-11-02 실측, 2026-11-04 저장소에 반영. 원시 결과는 [grid_2026-11-02.json](../../evals/results/embedding/grid_2026-11-02.json)이다(78칸 요약, 문항별 순위·상위 5·단계별 시간). 요약은 루트 [EVAL_REPORT.md](../../EVAL_REPORT.md) 1-3절에 있다.

- 목적: 임베딩 모델과 `vector(N)`을 정하기 위한 본평가다. 사전 등록은 `evals/guides/preregister.md` #16이다(측정 전에 커밋).
- 실행 환경
  - desktop-gpu(WSL2, RTX 3080 Ti 12GB)의 도커에서 돌렸다.
  - 실험 DB는 `sojafit-embed-db`(PostgreSQL 16.15, pgvector 0.8.7)다. 맥의 앱 DB와는 따로다.
  - 실행 이미지는 `sojafit-embed-run`이다. 11-01의 `sojafit-emb`에 psycopg 3.3.6, pgvector 0.5.1, rank-bm25 0.2.2, openai 3.40.0, voyageai 0.5.0을 더했다.
  - 저장소 스냅샷은 main `98c2fe8`이다.
- 입력
  - 평가셋은 `evals/dataset_v1.jsonl`(sha256 `2fef02c2…`)의 관련 25건 중 데이터시트 gold가 있는 19건이다. 회로 근거만 있는 6건(e01·e02·m01·m02·h01·h02)은 뺐다.
  - 카드는 `chunks.jsonl`(sha256 `9e62fb6a…`)의 52,244장이다. 서로 다른 본문 45,898개, 문서 1,360건이다.
- 방법
  - 카드 벡터는 모델마다 새로 만들었고 기존 캐시는 쓰지 않았다.
  - dense는 실험 DB에서 pgvector 정확 검색(`<=>`, 인덱스 없음)으로 상위 50장을 찾았다.
  - BM25는 저장소 `tokens()`와 BM25Okapi 기본값으로 상위 50장을 찾았다(점수 0 제외).
  - 하이브리드는 RRF k=60이다.
  - 리랭커(Voyage `rerank-3`, `rerank-3-lite`)에는 후보 전부를 넣고 상위 5장을 받았다.
  - 지표 계산은 `evals/run_retrieval.py`와 같은 기준이다(문서 순위, 쪽 적중). 다중 근거 Recall@5는 문항의 모든 gold 쪽이 상위 5에 함께 들어온 비율이다.
- 파일
  - 원시 결과: `evals/results/embedding/grid_2026-11-02.json`
  - 실행 스크립트(`embed.py` 카드 적재와 모델별 임베딩, `grid.py` 78칸 측정, `Dockerfile` 실행 이미지), 리랭크 응답 캐시(`rerank_cache.jsonl`, 133KB), 모델별 임베딩 기록과 실행 로그, 78칸 비교 그래프(`compare.html`)는 저장소 밖 실험 폴더에 있다. 이 문서의 표와 숫자가 그 요약이다.
