- 관련 문서: [OSC 작업 기록](../../worklog/osc.md)

## 1. 질문과 결론

질문: 내부 코퍼스 근거(1등급), 제조사 공식 PDF 행(2등급), 같은 품번의 인터넷 참고 링크(3등급)가 코드에서 어떻게 이어지고, 어디까지 검증됐는가.

| 항목 | 결론 | 근거 |
|---|---|---|
| 동작 | 3절 | 스펙, 코드 |
| 시험 | 기능별 단위 시험이 있다 | `tests/services/test_datasheet_rows.py`, `tests/multi_agent/test_docs_agent.py`, `tests/multi_agent/test_judge.py`, `tests/multi_agent/test_agents.py`, `tests/conversations/test_dto.py` |
| 레포에 원시가 있는 모델 측정 | 없음 | 5절 |
| 운영 부하, 안정 포화점 | 미확정 | 5절 |

## 2. 범위

| 포함 | 제외 |
|---|---|
| 1~3등급 동작, 코드 책임, 레포에 없는 측정의 결과 표 | 회로도 후보 검색 개선, 원본 회로 이미지 전달, 프런트 변경, 운영 서버 부하 |

## 3. 사용자에게 제공하는 동작

| 등급 | 자료와 채택 조건 | 호출과 출력 |
|---|---|---|
| 1 | 이미 보유한 코퍼스의 같은 품번·판본 근거 | 내부 검색과 카드 읽기. 충분하면 외부 호출 생략 |
| 2 | 허용 제조사 공식 PDF에서 확인한 정확한 품번, 페이지, 표 행, 값, 단위, 시험 조건 | Exa가 후보를 찾고 백엔드가 원문을 검증. `[W1]` 형식의 인용과 원문 URL, `source_sha256` 제공 |
| 3 | 1·2등급에서 검증 근거를 얻지 못한 경우 같은 품번의 인터넷 참고 링크 | `[R1]` 인용으로 미검증 참고임을 표시. 인터넷 숫자로 정격이나 대체 승인을 확정하지 않음 |

- 매 질문이 세 등급을 모두 거치지 않는다. 판본을 지정하면 다른 판본의 정격값으로 대체하지 않는다. 정확 품번을 확인하지 못하면 유사 품번의 값으로 답하지 않는다. 3등급까지 불충분하면 거절·부분 답변 경계를 유지한다.
- 공식 PDF 원문은 DB에 코퍼스로 적재하지 않는다. 대화 재조회에도 같은 인용 정보를 보존한다.
- 문서 질문의 공식 행 답변과 대체 판정의 VRRM 보충은 서로 다른 채택 경로다.

## 5. 레포에 원시가 없는 측정 (미확인)

아래 값은 작성자 로컬 작업공간의 기록이며 저장소에 원시 파일이 없다. 재현하거나 감사할 수 없다.

원시 위치(로컬): `v3-품질수정-20261112/범위고정_최종50/`, `v3-품질수정-20261112/공식검색/`, `v3-16-20-안내수정-20261112/`, `v3-최종코드-포화실측-20261112/`. 파일 이름은 `http.jsonl`, `answers-for-audit.json`, `review-judge.json`, `review-docs.json`, `citation-audit.json`, `measurement.json`, `verification.json`, `saved-replay.json`, `summary.json`, `decision.json`, `provider-failures.json` 등이다. 비밀번호, 쿠키, 키 파일은 첨부하지 않는다.

### 5.2 동결 v3 50문항 품질 검증

평가셋, 정답, 해시는 유지했다. 수정 전 코드의 결과이며 현재 코드의 새 전체 품질 점수가 아니다.

| 회차 | 답변 | 거절 | 입력대기 | 오류 | p95 (초) |
|---|---:|---:|---:|---:|---:|
| 수정 전 대표 회차 | 23 | 25 | 2 | 0 | 22.8051 |
| 범위 고정 후 마지막 전체 회차(동시 8) | 25 | 25 | 0 | 0 | 25.3538 |

- 원래 수정 대상: v3-09, v3-11, v3-13, v3-14, v3-15, v3-16, v3-20, v3-21, v3-23, v3-25, v3-07, v3-12.
- 마지막 전체 회차에서 v3-16, v3-20에 잘못된 미완료 안내가 남았다. 두 질문만 각 1회 다시 요청해 안내 제거, 핵심 본문과 숫자·W 인용 유지, GET 재조회 일치를 확인했다(21.2092초, 16.0182초). 실제 모델 응답 9건은 모두 Haiku 5.5. v3-20의 미검증 R 링크는 3개에서 0개로 바뀌어 모든 참고 footer가 같다고 말할 수 없다.
- 인용 위치 122항목 불일치 0은 문서·페이지·표 위치 검사이며 문장 의미 정답률이 아니다.
- 속도 개선으로 보고하지 않는다.

### 5.3 격리 부하 실측

조건: Haiku 5.5 고정, 코퍼스 1,360문서 / 51,967청크, 단계별 최대 250건(v3 x 5), 독립 계정, 응답 완료 후 2.05초 대기. 로그인·업로드 준비 제외, 분석 POST부터 최종 SSE까지. 단일 로컬 Uvicorn + Docker DB, 논리 CPU 16, 메모리 31.31 GiB, 같은 PC의 부하 도구.

| 단계 | 실제 요청 | 답변/거절/입력대기/오류 | 전체 p95 (초) | 정상 p95 (초) | steady 정상처리/초 |
|---|---:|---|---:|---:|---:|
| load-16 | 250 | 120/126/2/2 | 20.72 | 20.05 | 1.248 |
| load-32 | 250 | 123/124/2/1 | 35.83 | 35.83 | 1.282 |
| load-16-repeat | 250 | 122/124/3/1 | 18.26 | 18.26 | 1.349 |
| load-32-repeat | 250 | 122/125/2/1 | 32.64 | 32.46 | 1.496 |
| load-48 | 250 | 121/125/4/0 | 42.26 | 42.26 | 1.478 |

- 정상은 API completed·refused 상태이며 내용 정답 판정이 아니다. p95는 오름차순 95% 위치(250건이면 238번째).
- 48에서 64 동시로 steady 처리량 13.42% 감소, p95 42.26초에서 67.02초 증가.
- load-48-repeat는 85번째 결과에서 5/85 실패로 사전 5% 중단 기준에 도달했다. 진행 중 요청을 마무리한 132건의 실패는 11건(8.33%): LLM OpenAIRateLimitError 10건, 실행 예산 1건. 64 재확인은 실행하지 않았다.
- 유효 1,632건, 도구 보정 전 진단 250건은 별도 보존. 실제 모델 응답 3,981건 모두 Haiku 5.5.
- 제품 115파일 snapshot digest `c47bb9c6e42a1917ef7d199884250b5aa207721b3ca8769f950342c3825ebed5`, 측정 때 기록한 동결 v3 SHA256 `2b99b2125d98db6f127d4364e2940acaf4a27aeb9ee60ef1667d5e0e3e6e5e91`은 시작과 끝이 같다. 현재 `evals/FROZEN.json`의 `dataset_v3.jsonl` sha256은 `05202314ed1d009593ab14bc5d44e3d7ab7dd4a9f7e726f98282198c7999b4fd`다.
- 일일 예약 토큰 한도만 사용자 4천만, 서비스 2억 8천만, 일일 USD 50으로 격리 설정했고 요청별·공급자 제한은 유지했다. 보수적 누계 USD 10.0090553(실청구액 아님). 유효 비교 전과 64단계 전에 API를 재시작해 인메모리 캐시가 초기화됐을 수 있다.

## 6. 한계

- 5절 전체가 레포에 원시가 없는 값이다.
- 안정적인 포화 지점과 운영 최대 수용량은 미확정이다. 제공자 분당 한도와 리셋 시간은 확인하지 않았다. 운영 서버 부하는 측정하지 않았다.
- 5.3의 측정은 통합 전 코드의 값이다. 이후 코드에 대해 유료 답변 평가와 포화 재측정을 하지 않았다.
- 이후 수정(판본 연결, 검색 슬롯 상한 1+1, 공식 조회 제한 후 `partial`)은 가짜 검색·모델·사양과 실제 코드 경로를 쓰는 회귀 시험으로만 검증했다. 실제 Exa, PDF, LLM 호출 평가는 하지 않았다. 실제 모델 오답률이 개선됐다고 주장하지 않는다.
- v3-04, v3-41의 반복 안정성과 v3-17, v3-18, v3-19, v3-22, v3-24의 추가 세부 누락은 후속 목록에 남아 있고 추가 구현·재평가하지 않았다.
- 표시 지원 제조사는 TSC, Infineon뿐이다. 3등급 참고 링크는 미검증 정보다.
