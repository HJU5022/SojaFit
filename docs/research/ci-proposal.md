# CI 사용량 절감 보완 제안

**합의 전 제안이며 이 PR에서 workflow를 변경하지 않습니다.** 브랜치·push·리뷰·병합·uv 규칙은 기존 AGENTS를 따릅니다. 해당 규칙을 이 문서에서 다시 정의하지 않습니다.

## 현재 설정과 제안

| 항목 | 현재 | 추가 검토 |
|---|---|---|
| 실행 이벤트 | 테스트는 PR, Secret Scan은 PR·main push | 이미 제거한 중복 trigger는 유지 |
| 오래된 검증 취소 | concurrency 없음 | PR별 그룹으로 이전 검증만 취소. 배포·DB 변경처럼 부수효과가 있는 실행은 분리 |
| 실행 시간 | job timeout 없음 | 각 job과 외부 호출에 유한 대기 시간 설정 |
| 설치·캐시 | 테스트에서 `uv sync --locked` | uv 캐시를 런타임·pyproject.toml·uv.lock에 맞춰 구성. 필요한 의존성만 설치 |
| 변경 범위 | 모든 PR에서 테스트 전체 실행 | 순수 설명 문서는 저비용 검증, 제품·공통 계약·평가 변경은 관련 검증 실행 |
| 무거운 검증 | 별도 실행 방식 미정 | 실제 모델·전체 평가·긴 E2E는 책임자·시점·증거를 정해 분리. 필요한 검증을 생략하는 뜻은 아님 |
| Artifact·matrix | 별도 정책 미정 | 검토에 필요한 결과만 보존하고 환경 조합은 실제 지원 범위로 제한 |

## 선택 실행을 도입할 때의 조건

- `docs/**`나 확장자만으로 설명 문서를 판정하지 않는다. AGENTS·Spec·Skill·평가 규칙처럼 동작에 영향을 주는 문서는 관련 검증 대상으로 본다.
- 삭제·이름 변경의 이전/새 경로와 혼합 변경을 포함한다. 미분류 경로는 검증 범위를 넓히고, 변경 파일 목록을 얻지 못한 경우는 실패로 처리한다.
- 모든 PR에 결과를 남기는 필수 집계를 제안한다. 실행 대상의 실패·취소·결과 누락·예상 밖 skip을 통과시키지 않는다. 순수 설명 문서에서도 비밀값 검사는 유지한다.
- 동결 해시와 가벼운 평가 회귀는 일반 검증에 남긴다. 실제 모델 평가를 재생/fixture 결과로 대체하지 않는다.
- 재실행은 일시 장애 원인을 확인한 뒤 제한적으로 한다. 실행 job 수·사용 시간·캐시·artifact 사용량으로 절감 효과를 확인한다.

위 항목은 실제 workflow·선택 분류·집계 검증과 팀 합의 후 적용한다. 문서 작성, 로컬 정적 검사, Actions 실행 성공, 관리자 설정 완료를 구분하며 러너 미기동을 검사 통과로 보고하지 않는다.
