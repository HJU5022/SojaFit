# 웹 검색 TSC 필터 유무 비교 결과

> 실측일 2026-11-03 · 기존 결과를 본 30문항 반복 탐색 · 팀 의사결정용

## 목적과 방법

현재 Exa 검색 코드의 TSC 도메인 제한이 원하는 데이터시트를 찾는 데 어떤 영향을 주는지 세 도구에서 각각 비교했다. 프로젝트 manifest에서 고정한 동일한 30문항을 각 도구에 필터 없이 1회, TSC 필터를 적용해 1회씩 호출했다. 각 조건의 결과 상위 5개를 비교했으며, 최대 15초·재시도 없음으로 실행했다.

- Exa: 인증 Search API, type auto. 필터에는 includeDomains를 사용했다.
- Tavily: 인증 Search API, Basic. 필터에는 include_domains와 restrict를 사용했다.
- Brave: 인증 Search API. 필터에는 질문 뒤 site:taiwansemi.com 검색 연산자를 사용했다.
- 조건 순서에 따른 영향을 줄이기 위해 홀수 문항은 무필터를 먼저, 짝수 문항은 필터를 먼저 실행했다.
- 질문에는 기존 문서명과 과거 개정판이 포함돼 있다. 이전 30문항 결과를 이미 봤으므로 독립 평가가 아니다.
- Brave의 site 연산자는 질문 자체를 바꾸며 공급자도 실험 기능으로 안내한다. 세 도구의 필터 구현이 완전히 같다는 뜻은 아니다. [Brave 검색 연산자 안내](https://api-dashboard.search.brave.com/documentation/resources/search-operators)

## 전체 결과

| 도구 | 조건 | 정상 응답 | TSC 공식 도메인 출현 | 과거 manifest 주소 일치 | 응답 시간 중앙값 |
|---|---|---:|---:|---:|---:|
| Exa | 필터 없음 | 30/30 | 26/30 | 23/30 | 1,328.39ms |
| Exa | TSC 필터 | 30/30 | 30/30 | 24/30 | 1,477.78ms |
| Tavily | 필터 없음 | 30/30 | 26/30 | 5/30 | 1,863.58ms |
| Tavily | TSC 필터 | 30/30 | 30/30 | 5/30 | 1,901.81ms |
| Brave | 필터 없음 | 30/30 | 30/30 | 9/30 | 585.53ms |
| Brave | TSC 필터 | 30/30 | 30/30 | 9/30 | 505.18ms |

- **정상 응답:** 각 조건에서 API가 정상 형태로 응답한 문항 수다. 전체 180회 중 실패와 미실행은 없었다.
- **공식 도메인 출현:** 상위 5개에 taiwansemi.com 또는 하위 도메인 주소가 하나라도 포함된 문항 수다. 필터 적용 조건에서는 공식 도메인으로 제한하는 목적이 있으므로 이 수치가 높게 나오는 것은 예상되는 결과다.
- **과거 주소 일치:** 상위 5개에서 해당 문항의 과거 manifest URL과 호스트·디코딩된 경로가 일치한 문항 수다. 대소문자를 무시하고 스킴과 쿼리 문자열은 비교하지 않는다. 다른 주소의 같은 PDF는 놓칠 수 있다.
- **응답 시간 중앙값:** 성공 요청의 중간 시간이다. 서로 다른 공급자의 통신 방식·캐시·처리 시간이 달라 엔진 자체의 성능 차이라고 단정할 수 없다.

## 같은 질문끼리 비교

| 도구 | 필터 적용 후 주소 일치가 새로 생긴 문항 | 기존 일치가 사라진 문항 | 해석 |
|---|---:|---:|---|
| Exa | 1건 (S23) | 0건 | 이번 표본에서 필터로 일치가 23건에서 24건으로 늘었다. 품질 개선이 일반적으로 보장된다는 뜻은 아니다. |
| Tavily | 1건 (S13) | 1건 (S29) | 전체 일치 건수는 5건으로 같았지만 맞은 문항은 달라졌다. 총합만 보면 변화를 놓친다. |
| Brave | 0건 | 0건 | 과거 주소 일치 여부가 바뀐 문항은 없었다. 다른 검색 결과나 순위는 달라졌을 수 있다. |

필터를 적용한 응답 상위 5개에서는 세 도구 모두 TSC 외 도메인 주소가 관찰되지 않았다. 이는 도메인 필터의 동작 확인이며 PDF의 정확성을 보장하지 않는다.

## 바뀐 3문항의 공개 PDF 별도 확인

검색 API 재호출 없이 기존 manifest의 공개 TSC 원본 URL을 직접 각각 1회 조회했다. PDF 원문은 메모리에서만 처리하고 저장하지 않았다. 각 문서의 PDF 서명·파싱과 과거 manifest의 SHA-256을 확인했으며, 문서명·개정판 문자의 존재는 보조적으로 확인했다.

| 문항 | 선택한 이유 | PDF 응답·파싱 | manifest 해시 일치 | 문서명 문자열 | 개정판 문자열 |
|---|---|---|---|---|---|
| S23 | Exa 필터 적용 후 주소 일치 증가 | 성공 | O | O | O |
| S13 | Tavily 필터 적용 후 주소 일치 증가 | 성공 | O | O | O |
| S29 | Tavily 필터 적용 후 기존 일치가 사라짐 | 성공 | O | 확인되지 않음 | O |

S29는 원본 해시는 기존 manifest와 일치하지만, 단순 문자열 방식으로는 manifest 문서명 전체가 추출 텍스트에서 확인되지 않았다. 이 결과만으로 문서가 틀렸다고 판단할 수 없으며, 표지·품번 범위를 수동으로 대조해야 한다. 세 문서 모두 개정판 문자가 발견됐지만 그 문자만으로 위치·맥락이나 부품의 전기적 조건까지 검증한 것은 아니다.

## 프로젝트 적용 시 해석

이번 표본에서는 Exa의 TSC 필터 적용 시 과거 주소 일치가 1건 늘고 줄어든 건은 없었다. 현재 구현의 필터를 바로 제거할 근거는 관찰되지 않았다. 다만 30건의 단일 반복이며 과거 주소와 문서명을 알고 만든 질문이므로, 모든 실제 사용자 질문에서 필터가 낫다는 결론은 내릴 수 없다.

현재 MCP 서버는 Exa 결과 중 HTTPS TSC 공식 도메인 URL만 미검증 후보로 반환한다. 다음 단계에서는 공식 PDF 접근, 요청 품번·개정판의 정확한 대조와 기존 코퍼스 검증 관문 연결, 실제 질문 및 문서가 없는 경우를 포함한 평가가 필요하다.

## 비용과 기록 범위

- 사용자 확인: 세 계정 모두 사전에 필요한 무료 크레딧이 남았고 자동 과금·충전이 꺼져 있다.
- 계획상 최대 사용: Exa Auto 60회 무료분 전 $0.42, Tavily Basic 60크레딧, Brave 60회 무료분 전 $0.30. 실제 계정별 차감·청구 내역은 확인하지 않았다.
- 검색 API 키·응답 원문·결과 URL은 저장하지 않았다. 사용한 TSC manifest 참고 URL은 프로젝트에 기존에 있던 자료다.
- Brave의 API 결과에 대한 파생 통계 보관·공유 가능 범위는 공급자 확인이 필요하다. 공개 PDF 확인은 별도로 사전등록했고, 검색 비교의 180회에는 포함하지 않는다.

## 재현 자료

- 30개 고정 질문과 과거 manifest 참고 URL (원본 파일은 저장소 외부에 보관)
- 필터 비교의 질문별 집계 (원본 파일은 저장소 외부에 보관)
- 필터 비교 실행기 (원본 파일은 저장소 외부에 보관)
- 3개 PDF 확인 결과 (원본 파일은 저장소 외부에 보관)
- PDF 확인 실행기 (원본 파일은 저장소 외부에 보관)
