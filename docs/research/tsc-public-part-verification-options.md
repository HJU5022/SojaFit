# 코퍼스 밖 TSC 품번의 공개 확인 방안

> 팀 논의용 초안 · 2026-11-03 · 아직 채택된 방안 아님

## 결정할 질문

코퍼스 밖 TSC 품번도 공식 문서를 실시간 조회한다는 기존 SPEC을 유지하면서, 비공개 품번을 외부에 보내지 않으려면 **어떤 공개 품번 목록으로 사전 확인하고, 목록에 없는 품번은 누가 어떤 절차로 확인할까요?**

## 현재 프로젝트와의 관계

- [SPEC 2절](../../SPEC.md): 코퍼스에 없는 TSC 문서는 공식 사이트에서 실시간으로 받은 후 검증하고 판정한다. 근거가 부족하면 문서로 확인 안 됨으로 표시한다.
- [SPEC 6절](../../SPEC.md): 새 문서에는 PDF 확인, SHA-256 기록, 파싱 오류 0, pdfplumber 대조 등 검증 관문이 필요하다. G5 평가는 기존 코퍼스만 쓰고 실시간 조회를 끈다.
- 현재 STH의 MCP 초안은 기존 manifest의 일치하는 TSC 문서 ID만 외부 검색한다. 따라서 목록 밖 품번을 찾는 SPEC의 흐름은 아직 지원하지 않는다. manifest 문서명은 개별 품번 목록과 같지 않을 수 있다.
- manifest는 과거 공개 출처 기록이며 현재 공개 상태와 최신성을 보장하지 않는다. 공개 품번이라도 **검색 사실 자체**가 외부에 노출될 수 있다.

## 선택지

| 방안 | 사전 확인과 처리 | 장점 | 한계와 사전 확인 사항 |
|---|---|---|---|
| **1. 공개 품번 목록 별도 관리** | TSC 공식 자료 등 신뢰한 출처로 목록을 미리 만들고 로컬에서 정확히 대조한다. 목록 밖 품번은 차단한다. | 개별 사용자 품번을 외부에 보내기 전 대조 가능. 팀이 출처를 관리할 수 있다. | 목록 범위·갱신 주기·담당자와 자동 수집·저장 허용 조건이 필요하다. 미등록 공개 품번도 차단된다. |
| **2. 담당자 확인 후 목록 추가** | 미확인 품번은 검색을 멈추고, 담당자가 승인된 절차와 공식 근거를 확인한 뒤 공개 목록에 등록한다. 이후 검색을 허용한다. | 사람이 근거와 예외를 검토할 수 있다. 1번의 목록을 점진적으로 넓힐 수 있다. | 처리 지연과 담당자 부담이 있다. 담당자에게 품번을 전달하는 것과 확인 과정에서 외부 전송하는 것도 각각 승인 범위가 필요하다. |
| **3. 사용자 확인 후 검색** | 전송할 품번·공급자를 사용자에게 보여 주고 확인을 받으면 검색한다. | 새로운 품번을 빠르게 처리할 수 있다. | 사용자 확인은 공개 여부의 증명이 아니다. 외부 전송을 허용하므로 현재 ‘공개로 확인된 품번만 허용’ 결정보다 완화된 정책이며 팀의 별도 결정이 필요하다. |
| **4. 제조사 서비스 직접 확인** | 제조사 카탈로그나 검색 기능으로 품번을 확인한다. | 공식 출처와 대조할 수 있다. | 개별 품번을 조회하면 제조사에도 해당 품번이 전송된다. 현재 정책을 만족하려면 **품번 전송 없이** 확보한 목록으로 먼저 확인하거나 별도 전송 권한이 필요하다. API 존재·접근·이용 조건은 미확인이다. |

## 논의 출발안: 1번 + 2번

공개 품번 목록을 코퍼스와 별도로 관리하고, 목록에 없으면 외부 검색을 중단한다. 미확인 건은 권한 있는 담당자에게 내부적으로 전달해, **전달·외부 확인에 관한 권한과 절차를 먼저 확정한 뒤** 검토한다. 승인된 공개 근거가 확인되면 목록을 갱신하고 이후 검색할 수 있다. 확인할 수 없는 경우에는 판정 근거가 없음을 사용자에게 안내한다.

이 조합은 현재 공개 품번만 전송한다는 결정과 맞지만, 사람의 확인과 목록 갱신까지 즉시 실시간 조회를 보장하지는 않는다. 코퍼스 밖 품번의 실시간 조회 요건을 어떻게 충족할지 별도 합의가 필요하다. 사용자가 ‘공개’라고 확인하거나 정규식에 맞는 것만으로는 공개 근거로 삼지 않는다.

## 팀에서 결정할 항목

- [ ] 채택 방안과 조합: 1 / 2 / 3 / 4 / 기타
- [ ] 공개 확인 근거: 허용할 공식 자료와 제품·품번의 정확한 일치 기준, 개정·시리즈 처리
- [ ] 품번 목록: 최초 출처, 자동 수집·보관 조건, 갱신 주기, 책임자, 삭제·수정 절차
- [ ] 목록에 없을 때: 내부 요청 대상, 사용자 동의와 외부 전송 허용 여부, 검토·승인·기록 방법, 확인 불가 시 응답
- [ ] 전송 범위: 품번·제조사·개정 중 허용 항목, 검색 공급자와 보관·로그 정책 확인
- [ ] 검증 및 운영: 검색 결과와 판정 근거의 구분, PDF 검증 관문, 데모·G5 동작, 비용·요청 상한
