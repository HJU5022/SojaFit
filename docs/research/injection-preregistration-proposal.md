## 2026-11-11 SPEC 7절 실행기 추적 반영 제안

`SPEC.md`의 "그래프 평가 실행(`evals/runners/run_graph.py`)은 문항마다 CallbackHandler" 문단에 `run_injection_baseline.py`의 승인된 live 실행도 추가할 것을 제안한다. 항목별 trace ID/URL, 실행 세션, 사례·반복·정상/공격·방어 조건, trace_origin=live를 남긴다. T6 준비 턴도 같은 항목에 묶고 plan/simulate는 전송하지 않는다. 키 없음/추적 비활성화는 disabled, 초기화·콜백 생성 실패는 unavailable, 추적 요청은 queued로 기록한다. queued나 URL은 서버 수신 확인이 아니다. 종료·항목 오류에도 flush를 시도하며 추적 오류로 평가 결과/예산을 바꾸지 않는다. 합성 입력·근거·모델 입출력은 팀 비공개 프로젝트에만 전송하고 키·DB 문자열·정답 메타데이터는 제외한다. 과거 110건 가져오기는 수행하지 않는다. 실제 SPEC 및 사전 등록/승인/동결 평가셋은 수정하지 않는다. 실행기 해시가 바뀌므로 향후 유료 실행은 변경된 코드에 맞는 별도 승인·고정이 필요하다.
