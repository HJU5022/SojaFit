## 목적과 현재 상태

기존 코퍼스 검색, 문서 메타데이터, TSC 웹 후보, 로컬 PDF 무결성, 공개 회로 조회를 FastMCP stdio 도구로 제공한다. 도구를 직접 호출하는 초기 구현과 오프라인 테스트가 있다. 사용자 요청에서 LangGraph가 MCP 클라이언트로 호출하는 전체 경로는 아직 연결되지 않았다.

## 도구별 구현과 사용처

| 도구 | 구현된 기능 | 사용 상황 제안 | 한계·결정 필요 |
|---|---|---|---|

## 외부 검색과 데이터 경계

- 데모 모드에서는 외부 검색을 차단한다. 활성화된 경우에도 문서 ID를 manifest에서 확인하고, 출처·문서명·개정 형식이 일치할 때 구성한 검색어만 보낸다.
- 목록 밖 또는 확인되지 않은 문서는 `unverified`로 차단한다. 과거 manifest 출처 기록은 현재 공개 상태를 보장하지 않는다.
- 기존 SPEC의 코퍼스 밖 TSC 문서 실시간 조회와 비공개 품번 전송 방지 사이에서 공개 품번 확인 목록·갱신자·목록 밖 검토 절차를 팀이 결정해야 한다. [선택지](tsc-public-part-verification-options.md).
- Exa URL은 후보이며 PDF 본문·품번·개정을 검증하기 전 판정 근거로 사용하지 않는다. 외부 실험은 사전등록과 실제 지출 $0 조건 및 잔여 무료 한도를 확인한 뒤 진행한다.

## LangGraph와 연결 시 확인할 계약

확인 시점 원격 main의 단일 에이전트 `build_graph(retriever=None, checkpointer=None)`는 동기 검색기를 주입받는다. 라우팅 후 근거 검색·채점·재작성·응답 또는 거절로 분기하며 검색 상한은 2회다. STH MCP의 `search_corpus`를 연결하는 방향은 가능해 보이지만 통합 실행은 검증하지 않았다.

1. `retriever(query, *, parts=...)`의 입력과 카드 목록 출력, 품번 필터를 유지한다.
2. 동기 그래프 호출과 비동기 MCP 클라이언트의 세션·실행 수명을 정한다.
3. 빈 결과와 MCP·DB 장애를 구분하고 기존 재검색 상한 및 데모 조건을 유지한다.
4. 격리 DB에서 그래프 → MCP → 검색 → 결과·출처를 확인한다. 기존 사용자 DB나 볼륨을 초기화하지 않는다.
5. 회로 정보의 사용자 소유권, MCP 노출 범위, 문서 속 지시문을 데이터로 취급하는 경계를 그래프·서비스 담당자와 협의한다.
