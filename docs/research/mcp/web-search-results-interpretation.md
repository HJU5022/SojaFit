# 웹 검색 공급자 3종 30문항 탐색 결과

- 상태: 이력 (2026-11-03 탐색. 공급자 최종 선정 전 기록이며 선정 결정은 ADR에 없다. 현재 코드는 Exa를 쓴다: `backend/services/exa.py`, `backend/mcp_skill/mcp_server/server.py`의 `search_tsc_web`)
- 기준일: 2026-11-03
- 정본 여부: 정본(30문항 3공급자 탐색 수치). 도메인 필터 유무 비교는 [web-search-filter-comparison.md](web-search-filter-comparison.md), 후보 조사와 7질의 탐색은 [mcp-tool-candidates-draft.md](mcp-tool-candidates-draft.md)
- 관련 문서: [웹 검색 TSC 필터 유무 비교](web-search-filter-comparison.md), [MCP 서버 도구 6종](mcp-tool-implementation-plan.md), [사전 등록](../../../evals/guides/preregister.md)

## 1. 질문과 결론

질문: Tavily, Exa, Brave가 같은 30개 질문에서 TSC 공식 도메인과 기존 코퍼스 문서 주소를 얼마나 찾는가.

| 측정 항목 | Tavily | Exa | Brave | 해석 범위 |
|---|---:|---:|---:|---|
| 정상 응답 | 30/30 | 30/30 | 30/30 | 이 30건의 정상 처리. 장기 안정성·동시 요청 성능이 아님 |
| 공식 도메인 출현 | 28/30 | 27/30 | 29/30 | 상위 5개에 `taiwansemi.com` 또는 하위 도메인이 하나라도 있는 문항 수. 원하는 문서가 있다는 뜻이 아님 |
| 과거 문서 주소 일치 | 3/30 | 22/30 | 9/30 | 상위 5개에 해당 문항의 manifest `source_url`과 호스트·디코딩 경로가 일치한 문항 수. PDF 내용·최신판 일치는 확인하지 않음 |
| 응답 시간 중앙값 | 822.73ms | 1,302.87ms | 627.26ms | 호출 경로(SDK·MCP·HTTP)와 시점이 달라 엔진 속도 차이로 볼 수 없음 |

근거: 저장소 밖 결과 파일 `web-search-30-2026-11-03.json`(Exa·Brave), `tavily-authenticated-30-2026-11-03.json`(Tavily 인증). 저장소에 없으므로 재계산하지 않았다(한계 1).

공식 도메인 출현과 과거 주소 일치는 서로 다른 지표다. 상위 5개에 TSC의 다른 부품 페이지만 있어도 공식 도메인 출현은 O이고, manifest의 해당 문서 주소가 없으면 과거 주소 일치는 X다. 주소가 일치해도 PDF가 열리는지, 품번·개정판이 맞는지는 검증하지 않았다.

## 2. 방법과 환경

## 3. 결과 상세

### 3.1 Tavily 익명 1차와 인증 재측정

| 후보 | 정상 / 시도 | 미실행 | 공식 도메인 | 과거 주소 일치 | 성공 응답 중앙값 |
|---|---:|---:|---:|---:|---:|
| Tavily 익명 | 25/26 | 4 | 23/25 | 2/25 | 1,914.49ms |
| Tavily 인증 | 30/30 | 0 | 28/30 | 3/30 | 822.73ms |
| Exa 익명 MCP | 30/30 | 0 | 27/30 | 22/30 | 1,302.87ms |
| Brave 인증 | 30/30 | 0 | 29/30 | 9/30 | 627.26ms |

Tavily 익명은 26번째 요청(S26)에서 사용 한도 오류가 나 중단했고 S27~S30은 미실행이다. 정상 25건 공통 구간(S01~S25) 기준 공식 도메인은 Tavily 23/25, Exa 22/25, Brave 24/25, 과거 주소 일치는 각각 2/25, 18/25, 7/25다. 인증 재측정은 익명 결과를 이미 본 뒤 같은 질문으로 다시 실행했다. S01~S25의 과거 주소 일치는 익명·인증 모두 2/25이고 인증에서 S26이 추가로 일치했다.

### 3.2 후보별 관찰

| 후보 | 이번 결과에서 볼 수 있는 점 | 선택 전 확인할 점 |
|---|---|---|
| Tavily | 인증 재측정에서 30건 모두 정상, 공식 도메인 28건 | 과거 주소 일치 3건. 인증 방식에 따른 품질의 인과는 미확인 |
| Exa | 과거 주소 일치 22건으로 세 후보 중 최다 | 익명 호스팅 MCP는 사용 한도 오류가 있었다. 계정 기반 호출의 비용·한도·결과, PDF 검증 연동은 별도 확인 필요 |
| Brave | 공식 도메인 29건, 중앙값 627.26ms로 이번 측정에서 가장 좋음 | 과거 주소 일치 9건. API 데이터 보관 제한 때문에 출처 URL·로그·파생 통계의 보관 범위를 공급자에게 확인해야 함 |

## 4. 결정에 미치는 영향

- 검색 결과는 공식 문서를 찾기 위한 후보다. 판정 근거는 기존 코퍼스 데이터시트 또는 공식 사이트에서 받아 프로젝트 검증 관문을 통과한 TSC 데이터시트다. 검색 발췌문이나 도메인 출현만으로 부품 사양을 판정하지 않는다.
- 이 측정으로 정해진 공급자는 없다. 현재 코드가 Exa를 쓰는 것은 코드 사실이며 선정 근거를 가리키는 ADR은 없다.
- 키 없는 Compose 데모와 공식 평가의 오프라인 조건은 유지된다(`SPEC.md` 6절).

## 5. 한계

1. 모든 수치의 원시 결과 파일이 저장소에 없다(저장소 밖 `web-search-30-2026-11-03.json`, `tavily-authenticated-30-2026-11-03.json`). 이 문서의 값은 기록 당시 문서의 것이고 재계산하지 않았다.
2. 30문항은 manifest에서 무작위로 뽑은 비동결 탐색 표본이다. 질문에 과거 개정판이 들어 있어 실제 사용자 질문과 다르다.
3. 세 도구의 호출 경로·시점이 다르고 Tavily 인증은 이미 본 문항의 재측정이다.
4. 별도 페이지·PDF를 내려받지 않았다. 문서 접근 가능성, 실제 판본, 내용과 시험 조건은 미검증이다.
5. 계정별 크레딧 차감과 실제 청구 금액은 대시보드에서 확인하지 않았다.
6. Brave 파생 통계의 보관·공유 가능 범위는 공급자 확인이 필요하다.
