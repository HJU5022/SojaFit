# 웹 검색 도구 실측 결과와 항목별 해석

> 팀 논의용 초안 · 실측일 2026-11-03 · 공급자 최종 선정 전

## 1. 측정 목적과 조건

SojaFit은 코퍼스에서 근거를 찾지 못한 TSC 부품에 대해 공식 문서 후보를 찾아야 한다. 이번 실험은 Tavily, Exa, Brave가 **같은 30개 질문**에서 공식 도메인과 기존 코퍼스 문서 주소를 얼마나 찾는지 살펴본 탐색이다.

- 질문: 프로젝트 manifest에서 기존 W01~W08 문서를 제외하고 무작위 추출한 30건. 각 질문에 문서명과 과거 개정판을 포함했다.
- 공통 조건: 질문별 1회, 검색 결과 상위 5개, 15초 제한, 재시도와 별도 PDF 다운로드 없음.
- 실행 방식: Tavily는 인증된 Python SDK Basic 검색, Exa는 익명 호스팅 MCP, Brave는 인증된 Search API다. Tavily 인증 실험은 익명 측정 결과를 이미 본 뒤 같은 질문으로 재실행했다.
- 예산: 실제 지출 상한 $0. 무료 사용량·크레딧 조건에서 실행했으며, Tavily와 Brave의 실제 크레딧 차감액은 확인하지 않았다.

## 2. 결과표와 항목별 해석

| 측정 항목 | Tavily | Exa | Brave | 항목 해석 |
|---|---:|---:|---:|---|
| 정상 응답 | 30/30 | 30/30 | 30/30 | 이번 30개 요청은 세 후보 모두 정상 처리됐다. 이 한 번의 결과로 장기간 안정성이나 동시 요청 성능을 보장하지 않는다. |
| 공식 도메인 출현 | 28/30 | 27/30 | 29/30 | 상위 5개 중 하나 이상이 taiwansemi.com 또는 하위 도메인인 문항 수다. 공식 출처를 찾을 가능성을 살펴보는 지표지만 원하는 문서가 있다는 뜻은 아니다. |
| 과거 문서 주소 일치 | 3/30 | 22/30 | 9/30 | 상위 5개 중 프로젝트 manifest의 과거 source_url과 호스트·디코딩 경로가 일치한 문항 수다. 이번 표본에서는 Exa가 가장 많이 일치했다. PDF 내용·최신판 일치는 확인하지 않았다. |
| 응답 시간 중앙값 | 822.73ms | 1,302.87ms | 627.26ms | 정상 요청 시간을 순서대로 정렬했을 때 가운데 값이다. 이번 실행에서 Brave가 가장 낮았다. SDK·MCP·HTTP API의 연결 방식과 측정 시점이 달라 엔진 자체의 속도 차이로 단정할 수 없다. |

### 두 검색 지표가 다른 이유

예를 들어 1N4148W 데이터시트를 찾았을 때 결과에 TSC의 다른 부품 페이지가 하나만 있어도 **공식 도메인 출현**은 O다. 그러나 프로젝트 목록에 기록된 해당 문서 주소가 상위 5개에 없다면 **과거 문서 주소 일치**는 X다.

과거 주소 일치는 호스트·디코딩 경로를 비교하며 대소문자를 무시한다. 주소가 바뀌었거나 다른 주소로 같은 PDF를 제공하면 불일치가 될 수 있다. 반대로 주소가 일치해도 실제 PDF가 열리는지, 요청한 품번과 개정판의 본문이 맞는지 검증한 것은 아니다.

## 3. 후보별 검토

| 후보 | 이번 결과에서 볼 수 있는 점 | 선택 전 확인할 점 |
|---|---|---|
| Tavily | API 키를 사용한 재측정에서 30건 모두 정상 응답했고 공식 도메인은 28건에서 나타났다. | 과거 주소 일치는 3건이었다. 이전 익명 실험은 26번째 요청에서 사용 한도에 도달했다. 인증 방식에 따른 인과관계와 실제 문서 정확도는 미확인이다. |
| Exa | 과거 주소 일치가 22건으로 이번 세 후보 중 가장 많았다. TSC 문서의 후보를 찾는 1차 구현 후보로 검토할 수 있다. | 앞선 익명 실험에서 사용 한도 오류가 있었다. 계정 기반 호출의 비용·한도·결과와 PDF 검증 연동을 따로 확인한다. |
| Brave | 공식 도메인 출현 29건과 중앙값 627.26ms가 이번 측정에서 가장 좋았다. | 과거 주소 일치는 9건이다. API 데이터 보관 제한에 비추어 출처 URL·로그 및 파생 통계의 보관 범위를 공급자에게 확인해야 한다. |

## 4. 프로젝트에 연결한 해석

검색 결과는 **공식 문서를 찾기 위한 후보**다. SojaFit의 판정 근거는 기존 코퍼스 데이터시트 또는 공식 사이트에서 받아 프로젝트 검증 관문을 통과한 TSC 데이터시트다. 검색 발췌문이나 도메인 출현만으로 부품 사양을 판정하지 않는다.

현재 실측을 바탕으로 **Exa를 1차 구현 후보로 검토**할 수 있다. 도구 확정 전 실제 PDF 접근·품번·개정판·내용을 확인하고, 일반 사용자 질문과 무료 한도·오류 상황을 포함해 다시 평가해야 한다. API 키 없이 시작하는 Compose 데모와 공식 평가의 오프라인 조건도 유지해야 한다.

## 5. 결과를 읽을 때 주의할 점

- 30문항은 manifest에서 무작위로 뽑은 **비동결 탐색 표본**이다. 제품 분류별로 균형을 맞춘 표본이나 전체 검색 품질의 최종 평가가 아니다.
- 질문에 과거 개정판이 명시되어 있어 실제 사용자 질문과 다를 수 있다. 과거 주소 일치가 최신성이나 정답률을 뜻하지 않는다.
- 세 도구의 호출 경로·시점이 다르고 Tavily는 이미 본 문항을 재측정했으므로 지연과 결과 차이에 영향을 줄 수 있다.
- 별도 페이지·PDF를 다운로드하지 않았다. 문서 접근 가능성, 실제 판본, 내용과 시험 조건은 미검증이다.
- Brave 응답 원문과 결과 URL은 저장하지 않았다. 이 문서에 사용한 파생 통계의 보관·공유 가능 범위도 공급자 확인이 필요하다.
- 무료 한도 조건으로 진행했다. 실측 후 계정별 크레딧 차감과 실제 청구 금액은 대시보드에서 확인하지 않았다.
