## 검색 확대 결과

TSC는 공식 제품 API·데이터시트의 응용 회로 경로를 사용하며 이 경로에서 GitHub로 넘어가지 않도록 했다. TI·STMicroelectronics·Analog Devices·onsemi·Infineon·Vishay는 등록된 공식 호스트에서 자료를 찾는다. 품번 접두어만으로 제조사를 지정하지 않으며, 여러 제조사의 정상 자료가 확인되면 제조사 지정을 요청한다.

### 실제 API·화면 결과

- TSC10품번을 접두어 없이 검색해 API200 10건·PNG17장 표시·출처·원본 링크 일치를 확인했다. 이 재검증은 기존 서비스 캐시 정책을 유지했으며 외부 공급자 재검색이나 PDF 재다운로드를 강제하지 않았다. 첫 조회 속도 실측과 구분한다.

## PDF 중복 제거 결과

같은 요청에서 검사한 PDF 원문과 통과한 회로 쪽수를 변환 단계에 전달해 재다운로드와 같은 내용의 재검사를 줄였다. URL·모델·제조사·원문 해시·시트 수를 확인하고 요청 종료·오류 때 임시 원문을 해제한다. 원문을 API 응답·서명 토큰·요청 간 캐시에 넣지 않는다.

### 중복 제거 전후 실측 비교표

## 후보 PDF 병렬 처리 결과

중복 제거를 유지하면서 등록 반도체6제조사의 연속 PDF 후보를 최대2개씩 다운로드·검사했다. 프로세스 공통 동시 검사 상한도2개다. 완료 순서가 달라도 결과는 기존 후보 순서로 처리하며 PNG 변환·모호성 판단·재시도 예산은 기존 순서를 유지했다.

### 병렬 처리 전후 실측 비교표

아래의 직전 순차 값은 위 중복 제거 후 실측값이다. 기존 순차 구현을 다시 실행하지 않았다. 같은 입력마다 API 컨테이너를 재시작하고 메모리·브라우저 HTTP 캐시를 비운 조건이며 서버 기동 시간은 제외했다.

|---|---:|---:|---|
| LM2596 | 21.249576 | 16.463492 | HTTP404 `ambiguous_manufacturer`, 기존 안내·이미지0 유지 |
| L7805 | 29.446198 | 25.012200 | HTTP200, STMicroelectronics·PNG3장 |
| LT1763 | 87.868889 | 97.733370 | HTTP200, Analog Devices·PNG2장 |
| NSVR351SDSA3 | 19.810348 | 12.438175 | HTTP200, onsemi·PNG1장 |
| BAT62-02V | 11.015185 | 9.189724 | HTTP200, Infineon RF 응용 회로·PNG1장 |

실제 검색7건 모두 최대 동시 검사 수2와 작업 구간 중첩을 확인했다. 정상6건의 선택 원문은 각각 다운로드1회·내용검사1회·재사용1회다. 원본 URL·제조사·SHA-256·시트 수가 직전 기록과 같고, PNG9건의 HTTP200·디코딩·화면 로드와 실제 시트 index별 바이트 해시 일치를 확인했다. 측정용 파일명의 도착 순서와 실제 API 시트 index를 구분해 대조했다.

정상6입력은4건 단축·2건 증가했고 모호성 조회는 단축됐다. 서로 다른 시점의 각1회 관측이며 후보·네트워크 조건이 달라 전체 지연 차이를 병렬화만의 효과나 보장된 개선율로 환산하지 않는다.

- ADI: 첫 후보 완료 전 구간은 약79.545→93.963초, 후보 이후는8.324→3.770초였다. 후보 수는5→4로 달랐다. 첫 구간을 Exa HTTP 단독 지연으로 분리한 값은 아니다.
- TI 지정: 후보2→3으로 바뀌었고 새 탈락 PDF의 다운로드6.463초·검사0.813초가 추가됐다. 후보 이후 구간은3.377→9.307초였다. 구간 값은 기존 API 시간과 서버 로그 시각으로 계산한 근삿값이다.

HTTP manifest 총8건은 인증401 1건·모호성404 1건·정상200 6건이다. 인증 실패는 공급자 검색 전 실패로 실제 검색7건과 별도로 집계했다. 공식 후보 검색 완료 로그9건은 Exa 성공 응답 뒤 기록한 이벤트이며 공급자 HTTP 직접 계측값과 구분한다.
