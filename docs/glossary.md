# 용어집

문서 · 주석은 아래 "쓰는 말"을 씁니다. 처음 보는 사람도 알아듣게 개발자들이 흔히 쓰는 말로 맞췄고, 예전에 쓴 말은 지난 기록을 읽을 때 찾아보라고 남깁니다.

## 검색 · 평가

| 쓰는 말 | 영어 | 뜻 | 예전에 쓴 말 |
|---|---|---|---|
| 청크 | chunk | DB(`document_chunks`)에 저장하는 검색 단위. 데이터시트 표 한 행 = 청크 하나이고, 문서마다 표지 청크 1개와 표 밖 글 청크가 더 있다(`backend/rag/pipeline/chunk.py`) | |
| 카드 | card | 표 한 행으로 된 청크. 판정 값과 후보 찾기는 카드 도구(`backend/rag/card_specs.py` · `card_find.py`)가 카드를 그때그때 읽는다(ADR 0016). 예전에는 청크 전체를 카드라고도 불렀다 | |
| 표지 청크 | cover chunk | 문서의 품번 목록만 적은 청크(`page_number` 없음). 서비스 검색은 늘 뺀다 | 표지 카드 |
| top-k | top-k | 검색이 돌려주는 상위 청크 k개(서비스 기본 5) | 상위 k장 |
| 정답 페이지 | gold page | 질문의 답이 적힌 데이터시트 페이지 | 정답 쪽 |
| 베이스라인 | baseline | 비교의 기준이 되는 설정 | 기준 |
| 평가셋 v1 · v2 · v3 | eval set | 동결한 공식 평가셋(`evals/dataset_v*.jsonl`, sha256은 `evals/FROZEN.json`). 기준은 v3(2026-11-10 동결) | |
| R1 검색 평가셋 | retrieval set | 검색만 재려고 사양 표로 정답 페이지를 정한 84문항(`evals/samples/retrieval_r1.jsonl`, 사전 등록 #25). 사람 판정은 없다 | R1 표본 |
| dev 세트 · test 세트 | dev / test (hold-out) | R1을 PDF 단위로 나눈 두 묶음. dev 46문항으로 조합을 고르고, 고를 때 쓰지 않은 test 38문항으로 확인한다 | 고르기용 · 확인용 |
| 사전 등록 | pre-registration | 측정 전에 조건 · 지표 · 기대 범위를 `evals/guides/preregister.md`에 커밋하고 측정 뒤 고치지 않는 것 | |
| 쿼리 재작성 | query rewriting | 검색 전에 LLM이 질문을 영어 검색어로 바꾸는 단계(`rewrite()`) | 질의 재작성 |
| 표지 청크 제외 | | 표지 청크를 검색 후보에서 빼는 필터(품번 필터와 함께 쓰면 "품번 + 카드 종류" 칸) | 표지 빼기 |

## 지표

| 쓰는 말 | 뜻 | 예전에 쓴 말 |
|---|---|---|
| Page Recall@k | 정답 페이지 중 top-k 안에 든 비율 | 쪽 회수율@k |
| Page Hit@k | 정답 페이지가 하나라도 top-k 안에 든 문항 비율 | 쪽 적중@k |
| Full Recall@k | 정답 페이지를 전부 top-k 안에 찾은 문항 비율 | 모든 근거@k |
| Page MRR | 첫 정답 청크 순위의 역수 평균(10위 밖은 0) | 쪽 MRR |
| Page nDCG@k | 정답 페이지가 위에 있을수록 높은 점수(같은 페이지는 한 번만 셈, 만점 1) | 쪽 nDCG@k |

## 판정

| 쓰는 말 | 뜻 | 예전에 쓴 말 |
|---|---|---|
| N승 M패 | 문항별로 견줘 나아진 문항 N개 · 나빠진 문항 M개 | |
| 개선 · 악화 | 순 차이(승 − 패) +5문항 이상이고 부트스트랩 95% 신뢰구간 하한 > 0이면 개선, 그 반대면 악화 | |
| 유의차 없음 | 개선 · 악화 기준에 못 미침. "같다"는 뜻이 아니다 | 차이 입증 못 함 |

## 바꾸지 않은 곳

- LLM이 읽는 글은 "카드"를 그대로 쓴다: `backend/prompts/`의 프롬프트, `backend/mcp_skill/`의 도구 설명, `backend/graph/nodes.py`의 채점 입력과 출력 스키마 설명. 바꾸면 모델 입력이 달라져 지난 측정과 견줄 수 없다.
- 데이터는 고치지 않았다: 동결 평가셋, `evals/samples/`의 jsonl, `evals/results/`의 측정 결과, `db/`의 SQL.
- 측정 결과 파일 안의 칸 이름(예: `part+kind`, `S2 +표지 빼기`)은 찍힌 그대로다.
- "모델 카드"(Hugging Face model card)는 청크와 다른 말이라 그대로 둔다.
