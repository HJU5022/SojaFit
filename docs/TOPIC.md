**회로를 읽고 대체 조건을 정해 후보 부품을 판정하는 RAG 에이전트 (첫 범위: 소형 MCU 회로의 다이오드)**

| 항목 | 내용 |
|---|---|
| 조, 구성원 | 2조 / 하정운(조장), 심태현, 오세창, 김재훈. 정답 판정은 하정운(전자 부사관 7년)과 김재훈(전자 부전공)이 맡는다. |
| 목표 직무와 산업 | **AI 에이전트 개발자(LLM·RAG 응용) / 제조(전자부품·하드웨어).** 강사 확인으로 사전 논의 없이 진행한다(2026-10-29). 제조 산업(전자·설비·제조사·제조AX 공급사) AI 공고 237건(중복 제거, 2026-10-29 조사)에서 열린 AI 개발 직무 170건, 그중 LLM·RAG·에이전트 명시 77건, 신입 가능 44건이다[2]. |
| 누가 | 소형 MCU(ATtiny85 등)로 시제품·소량 생산을 하는 하드웨어 개발자와 소규모 하드웨어 팀, 그리고 부품 견적을 승인하는 팀 책임자. 팀원의 실제 경험: ATtiny85 회로에서 제너·쇼트키 다이오드의 역할과 대체 조건을 몰라 원본 품번을 그대로 썼다. |
| 어떤 업무에서 | 단종·재고 부족·원가 절감으로 회로 부품을 바꿀 때마다 반복되는 일: 그 부품이 회로에서 맡은 역할을 파악하고, 역할에서 대체 조건을 정하고, 후보 부품의 데이터시트를 읽어 조건을 만족하는지 판단한 뒤 견적을 낸다. |
| 무엇을 묻는가 | ① "이 ATtiny85 보드(KiCad 넷리스트)에서 D1은 무슨 역할이야? 바꾸려면 어떤 조건을 지켜야 해?" ② "역극성 보호용 D1이 1N4007(1000V)인데, 이 5V 회로에서 더 작고 싼 다이오드로 바꿔도 돼? 후보마다 근거를 붙여 판정해 줘." ③ "D2(5.1V 제너)가 단종됐어. 같은 역할을 할 후보 3개를 찾고, 대체안과 수량·가격을 넣은 견적서를 저장하기 전에 보여 줘." |
| 지금은 어떻게 하는가 | 유통사 사양 필터나 대체품 검색으로 **원래 부품과 사양이 같은** 후보를 찾고, 그 회로에서 되는지는 회로와 데이터시트를 직접 읽어 판단한다. 사양 대조는 원래 부품 사양 이상만 찾으므로, 회로에 비해 과한 사양을 그대로 이어 쓴다. 공개 ATtiny85 계열 회로의 다이오드 554개(중복 파일 제외) 중 1N4148(100V)이 53개(저장소 9개), 1N4007(1000V)이 11개(저장소 3개)였다[4]. 제조사의 대체품 조회 도구는 동등성을 보증하지 않는다고 고지하고, 범용 챗봇이 존재하지 않는 품번을 대체품으로 제시한 사례도 보고됐다[3]. 불편한 점(가설): 역할을 모르면 따질 조건을 정할 수 없고, 사양만 맞춘 대체는 시험 조건(온도·전류) 차이를 놓친다. |
| 범용 챗봇과 무엇이 다른가 | 차이는 **근거 문서**에 있다. 판정마다 코퍼스에 있는 데이터시트의 쪽·표·행과 공개 문서의 절을 인용한다. 후보는 코퍼스에 있는 품번만 내고, 값이 없거나 조건이 다르면 "문서로 확인 안 됨"으로 둔다. 회로 넷리스트에서 역할을 읽어 따질 조건을 정하고, 값 비교와 단위 환산은 코드로 계산한다. 후보마다 동일품 / 사양 동등 / 역할상 충분 / 불충족 / 확인 안 됨 중 하나로 분류하고, 패키지가 다르면 기판 수정 필요를 표시한다. "같은 동작은 보장하지 않는다"를 답마다 밝히고, 견적서는 사람이 승인한 뒤에만 저장한다. 사양 기반 대체품 검색(Flux, Zenode)과 사용자가 넣은 조건의 정격 점검(SheetsData MCP)은 있지만, 회로 역할에서 조건을 도출해 판정하는 흐름은 찾지 못했다[3]. 범용 챗봇과 같은 질문 5개로 **근거 인용 비율, 없는 품번 제시 수, 확인 안 됨 처리 수**를 비교하고, 사양 대조로는 틀리고 역할 기반으로는 맞는 문항(과한 사양, 놓친 조건)을 평가셋에 넣어 차이를 숫자로 보인다. |
| 누가 쓰고 누가 지불하는가 | 쓰는 사람은 하드웨어 개발자, 견적을 승인하고 돈을 내는 사람은 소속 팀·기업(가설). 다른 가설: 부품 유통사가 견적에서 주문으로 이어지는 고객 확보용으로 제공하거나(반도체 회사의 설계 도구 회사 인수 사례: Renesas–Altium 2024), 제조AX 기업이 설비·회로 보전 업무 도구로 쓴다. 모두 인터뷰로 확인할 가설이다. |
| 코퍼스 후보 | ① **다이오드 데이터시트**: Taiwan Semiconductor 최소 1,099건(18개 분류 중 12개 집계), Infineon 약 280~430건. 두 회사 사이트 약관은 정보·비상업 목적, 비수정·고지 유지·출처 표기 조건으로 복제·배포를 허용한다. 다이오드 데이터시트 41건 실측에서 문서당 서로 다른 조각이 15.3개였으므로 약 2.1만~2.3만 조각을 예상한다[1]. ② **회로 역할·설계 지식**: Wikipedia 다이오드 분류(CC BY-SA 4.0), SparkFun Learn(CC BY-SA 4.0), KiCad 문서(GPL v3+ 또는 CC BY 3.0+, 2,116조각)와 심볼 라이브러리(CC BY-SA 4.0)[1]. ③ **평가·시연용 회로**: 공개 ATtiny85 KiCad 프로젝트 151개(MIT·CC BY-SA)에서 역할 후보 다이오드 75개를 찾았다[4]. 재배포를 금지하는 제조사(TI, Diodes, Vishay, ST, Nexperia, PANJIT)의 데이터시트는 넣지 않는다. 파싱 대상은 데이터시트 PDF 표(값·조건·각주)이고, 단위 기호가 깨지는 사례(μ→m)를 확인해 보정한다. |
| 범위 | MVP는 판정과 승인 후 견적서 저장까지다. 로그인한 사용자별로 승인된 판정·견적 사례를 쌓고, 다음 판정 때 비슷한 사례를 함께 보여 준다. 틀린 사례는 승인 절차를 거쳐 고친다. 가격·재고는 키 없이 도는 데모 모드에서 기록해 둔 응답을 쓰고, 확장 단계에서 Mouser API로 실시간 가격·재고를 조회한다. 실제 주문·결제는 확장 가능성으로만 둔다. |
