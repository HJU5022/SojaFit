# assets

## 역할
- 이 폴더: 문서가 그림으로 보여 주는 이미지와 그 원본을 둡니다.
- 넣는 것: `README.md`와 문서에 넣는 구조도 이미지(PNG)와 원본(SVG).
- 넣지 않는 것: 평가 결과 파일(`../../evals/results/`), Langfuse 화면 캡처(`../deliverables/langfuse/`), 데이터시트 PDF(`../../data/`).
- 담당: 평가·문서

## 파일

| 파일 | 유형 | 한 줄 설명 |
|---|---|---|
| `agent-flow.png` | 이미지 | 멀티 에이전트 구조도. `README.md` 3절이 보여 줍니다 |
| `agent-flow.svg` | 이미지 원본 | 위 그림의 원본. 글자·선을 고칠 때는 이 파일을 고친 뒤 PNG를 다시 만듭니다 |
