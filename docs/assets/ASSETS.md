# assets

## 역할
- 이 폴더: 문서가 그림으로 보여 주는 이미지와 그 원본을 둡니다.
- 넣는 것: `README.md`와 문서에 넣는 구조도 이미지(PNG)와 원본(SVG), 조사 문서가 본문에 그림으로 넣는 검증 화면 캡처(JPG, 날짜가 들어간 이름). 캡처는 찍은 날의 화면이며 지금 화면과 다를 수 있다(11-15 캡처 2장은 11-16 새 화면 교체 전 화면).
- 넣지 않는 것: 평가 결과 파일(`../../evals/results/`), Langfuse 화면 캡처(`../deliverables/langfuse/`), 데이터시트 PDF(`../../data/`).
- 담당: 평가·문서
