# SojaFit 개발 전용 전체 더미 흐름 설계

## 목표

현재 작업대의 로그인만 우회하는 더미 인증을 전체 사용자 흐름으로 확장한다. 사용자는 실제 백엔드·DB·LLM·가격 API 없이 프로젝트 선택, 회로 확인, D5 분석, 근거와 판정 확인, 사람 승인, 가격 조회, 가격 없는 견적 저장, 승인 사례 삭제까지 직접 조작할 수 있어야 한다.

더미 데이터는 production에서 실제 결과 대신 나타나지 않는다. 개발자가 `npm run dev:dummy`를 명시적으로 선택한 경우에만 켜지며, 화면 상단에 비영속 더미 상태를 계속 표시한다.

## 선택한 구조

### 공통 API 전송 경계

`frontend/src/api/client.ts`의 JSON 요청과 `openRunStream`의 SSE 요청을 하나의 전송 함수로 통과시킨다. 일반 모드에서는 기존 `fetch`를 그대로 호출한다. `import.meta.env.DEV`이면서 Vite mode가 `dummy`일 때만 개발 전용 메모리 백엔드로 전달한다.

이 방식은 화면 컴포넌트에 fixture 조건문을 흩뿌리지 않고 실제 API DTO와 동일한 데이터를 사용한다. Vite 서버 미들웨어나 새 mock 라이브러리도 필요하지 않다.

### 메모리 백엔드

더미 백엔드는 다음 최소 상태만 가진다.

- `breadboard_supply` 프로젝트와 D1 중심 연결 데이터
- 프로젝트별 thread 한 건
- D5 완료 run과 안전한 공개 결과 DTO
- 후보 승인과 승인 사례
- 가격이 없는 견적
- 조회 순간에만 반환하는 더미 가격·재고

상태는 모듈 메모리에만 존재한다. localStorage, sessionStorage, 쿠키, IndexedDB, 실제 DB를 사용하지 않는다. 새로고침하면 초기값으로 돌아간다.

### 실행 결과와 SSE

D5 실행은 `run_started` → `status` → `completed` 순서의 SSE 프레임을 반환한다. 완료 결과에는 역할 코드·이름 연결에 필요한 역할 목록, 역할 근거, 후보 판정, 데이터시트 위치, 가격 조회용 부품 번호만 포함한다. 전압·전류 등 확인되지 않은 조건은 만들지 않고 `missing` 또는 빈 값으로 둔다.

### 화면 표시

공통 셸에 `더미 실행 모드 · 저장되지 않음` 배지를 표시한다. 기존 다크 테마와 3열 작업대, 모바일 drawer와 결과 tab은 바꾸지 않는다. 더미 모드에서만 배지가 나타나며 일반 개발·production 화면에는 나타나지 않는다.

## 사용자 흐름

1. `npm run dev:dummy` 실행
2. 더미 로그인 상태로 `/app` 진입
3. `breadboard_supply` 프로젝트 선택
4. D1을 대상 부품으로 선택
5. 대체 질문 입력 및 D5 실행
6. 역할·근거·후보 판정 확인
7. 후보 선택 및 승인 확인
8. 더미 가격·재고 조회
9. 수량 입력 후 가격 없는 견적 저장
10. 승인 사례 삭제

## 오류와 안전 경계

- 더미 모드의 정의되지 않은 `/api` 요청은 실제 서버로 빠져나가지 않고 공통 404 오류로 끝낸다.
- AbortSignal이 취소되면 더미 응답도 중단한다.
- production에서는 mode 이름과 관계없이 `import.meta.env.DEV` 경계가 더미 백엔드를 차단한다.
- 비밀값, 실제 사용자 데이터, 실제 공급사 응답을 더미 데이터에 넣지 않는다.
- 가격·재고는 조회 응답에만 있고 승인·견적·사례 상태에는 저장하지 않는다.

## 검증

- 더미 라우터 단위 테스트로 endpoint, 상태 변화, 404, 취소를 검증한다.
- Playwright 전용 흐름은 `page.route` 없이 `npm run dev:dummy` 서버를 사용한다.
- 전체 흐름에서 회로·분석·근거·판정·승인·가격 조회·견적·삭제를 확인한다.
- 기존 프론트 단위 테스트와 production build를 실행한다.
- 브라우저에서 실제 클릭 흐름을 수행하고 다크 화면과 더미 배지를 확인한다.
- 최종 diff에서 운영 API 계약, 인증·소유권·가격 비저장 경계가 약화되지 않았는지 확인한다.

## 범위 밖

실제 KiCad 업로드 변환, LLM/RAG 실행, 공급사 호출, 영속 DB, 운영용 데모 backend, 실패 시 실제 API fallback, 관리자 화면 더미 데이터는 구현하지 않는다.

## 승인된 결정

- 자동 테스트만 실행하지 않고 현재 웹에서 사용자가 직접 끝까지 조작할 수 있게 한다.
- 개발 전용 메모리 백엔드를 공통 API 경계에 둔다.
- 새로고침 시 초기화하고 production에서는 사용할 수 없게 한다.
- 전체 흐름이 더미임을 화면에 지속해서 표시한다.
