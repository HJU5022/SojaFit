# superpowers

## 역할
- 이 폴더: 구현 전에 사용자와 합의한 설계와, 그 설계를 코드·테스트·검증 단계로 옮긴 실행 계획을 둡니다.
- 넣는 것: 승인된 설계 문서(`specs/`)와 구현 계획(`plans/`).
- 넣지 않는 것: 기능의 정본(`SPEC.md`), 기능 작업서(`docs/specs/`), 실험 사전 등록(`docs/experiments/`), 실행 결과(`evals/results/`).
- 담당: 각 기능 담당자.

## 파일
- `SUPERPOWERS.md` — 이 폴더 설명.
- `specs/` — 사용자와 합의한 설계 문서. 현재 `2026-11-05-supervisor-prompt-v0-design.md`가 있습니다.
- `plans/` — 승인된 설계를 구현하는 단계별 계획. 현재 `2026-11-05-supervisor-prompt-v0.md`가 있습니다.
