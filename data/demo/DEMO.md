# demo

## 역할
- 이 폴더: 키 없이 도는 데모 모드(`DEMO_MODE=1`)가 재생할 응답을 둘 자리입니다. 지금은 이 설명 파일만 있고 응답 파일은 하나도 없습니다. 재생 코드도 아직 없습니다(`backend/services/llm.py`가 읽을 예정).
- 넣는 것: 데모 가격표(가공값, `price_source = 'demo'`), 데모 시나리오용으로 만들어 사람이 검토한 LLM 응답(인용은 청크 id로만). Mouser 형식의 가격·재고 응답은 두지 않습니다(ADR 0009).
- 넣지 않는 것: 실제 API 응답 원본, 키, 데이터시트 원문 발췌(`data/corpus/`).
- 담당: 서비스·운영

## 파일
- 없음. 응답 파일을 만들면 이 목록에 한 줄씩 적습니다.
