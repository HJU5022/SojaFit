# demo

## 역할
- 이 폴더: 키 없이 도는 데모 모드(`DEMO_MODE=1`)가 재생하는 응답을 둡니다. `backend/services/llm.py`가 읽을 자리이며, 재생 코드는 아직 없습니다.
- 넣는 것: 데모 가격표(가공값, `price_source = 'demo'`). Mouser 형식의 가격·재고 응답은 두지 않습니다(ADR 0009). LLM 응답은 데모 시나리오용으로 만들어 사람이 검토한 것. 인용은 청크 id로만 적습니다.
- 넣지 않는 것: 실제 API 응답 원본, 키, 데이터시트 원문 발췌.
- 담당: 서비스·운영
