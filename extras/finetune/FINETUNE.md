# finetune

## 역할
- 이 폴더: 가산점용 파인튜닝(+5)의 학습 코드와 비교 결과를 둘 자리입니다. 학습은 서비스 밖에서 돌립니다. 아직 시작하지 않아 비어 있고 이 설명 파일만 있습니다.
- 넣는 것: 학습 스크립트와 설정(LoRA, QLoRA, PEFT 등), 학습 데이터 구성 설명, 베이스 모델과 같은 평가셋으로 잰 점수, 실제 출력 비교표.
- 넣지 않는 것: 학습한 모델 가중치(용량 때문에 Git에 넣지 않습니다), 평가셋 원본(`evals/dataset_v1.jsonl`), 서비스 코드(`backend/`).
- 담당: 가산을 시작할 때 정합니다

## 안내
"파인튜닝했습니다"만으로는 인정되지 않습니다. 베이스 모델과 같은 평가셋으로 잰 숫자와 실제 출력 비교표가 있어야 합니다. RAG 맥락에서는 임베딩 모델이나 리랭커의 파인튜닝도 인정됩니다.

## 파일
- 없음. 이 설명 파일뿐입니다. 학습 파일을 만들면 이 목록에 한 줄씩 적습니다.
