# multi_agent

## 역할

- 2026-11-11 T3 회귀: `test_agents.py`는 사양 조회의 넷리스트 미제공·문서 0건 모델 미호출과 역할 입력 보존을 검사한다. `test_docs_agent.py`는 실측03 원시 SHA를 대조하고 저장 T3 초기/재검색 응답을 재생해 인용 교정 성공/실패 양쪽의 사양 보존·부가 문장 제거와 혼합 역할 연결 답변을 확인한다. `test_supervisor.py`는 채택/실패/제외/앞 회차 보고의 넷리스트 권한을 검사한다. 외부 모델을 새로 평가한 결과가 아니다.
- 이 폴더: 멀티 에이전트(`backend/multi_agent/`)의 회귀 테스트를 둡니다. 소스 폴더와 같은 이름으로 짝을 맞춥니다(`tests/graph/` ↔ `backend/graph/`와 같은 규칙).
- 넣는 것: `test_<대상>.py`. LLM과 검색기는 가짜로 바꿔 API 없이 돌립니다.
- 넣지 않는 것: 단일 그래프 시험(`tests/graph/`), 평가 실행기와 동결 감시(`tests/evals/`), 판정 코드 시험(`tests/judge/`).
- 담당: 에이전트

실행: `uv run pytest -q tests/multi_agent`(저장소 루트).
