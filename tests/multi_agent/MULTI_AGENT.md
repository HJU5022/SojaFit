# multi_agent

## 역할
- 이 폴더: 멀티 에이전트(`backend/multi_agent/`)의 회귀 테스트를 둡니다. 소스 폴더와 같은 이름으로 짝을 맞춥니다(`tests/graph/` ↔ `backend/graph/`와 같은 규칙).
- 넣는 것: `test_<대상>.py`. LLM과 검색기는 가짜로 바꿔 API 없이 돌립니다.
- 넣지 않는 것: 단일 그래프 시험(`tests/graph/`), 평가 실행기와 동결 감시(`tests/evals/`), 판정 코드 시험(`tests/judge/`).
- 담당: 에이전트

실행: `uv run pytest -q tests/multi_agent`(저장소 루트).

## 파일
- `MULTI_AGENT.md` — 이 문서
- `test_build.py` — 조립: 그래프 모양(노드 이름 · 간선, RAG 고리 · 대체 부품 하위 그래프의 간선, 대체 부품을 끄면 그 노드가 없음, 간선에 라벨이 없음), Supervisor 길(일상 대화 → 끝내기, 범위 밖 · 형식 실패 → 거절, 품번 없음 사실이 Supervisor와 거절 문구에 닿는지, 가격 → 단일 그래프와 같은 가격 안내(검색 · HTTP 호출 없음, 값 없음)), RAG 길(Supervisor 1번 + LLM 1번, 근거 없음 → 검색으로 되돌아감, 2바퀴 상한 뒤 못 찾음 거절), 거절한 부분 붙이기, 대체 부품 길(인터럽트 한 번 재개, 읽기 LLM 1번, 코드 답 틀, 코퍼스 밖 요구 → 거절), 대체 부품이 꺼지면 RAG로, 켜지 않은 기능 거부, 새 턴에 칸 비우기
- `test_judge.py` — 판정 에이전트: 읽기 LLM 1번, 질문에 없는 숫자 버리기, 인터럽트 한 번과 재개 값, 규칙 없는 역할, 판정 · 찾기 · 정렬, 비교는 `verdict`에서만, 품번 앞 제조사 이름 떼기(TSC), 주문 코드만 다른 동일품과 주문 정보 표 인용(쇼트키 면제 뒤에도 동일품), 찾기에 원래 부품 패키지 · 분류 넘기기. 가짜 LLM · 가짜 사양 표
- `test_judge_read.py` — 판정 읽기: 읽기 입력 글에 역할마다 그 역할의 값 이름 · 종류가 있는지, 프롬프트가 모든 값 이름의 뜻을 담았는지, 그 역할의 이름은 남고 다른 이름은 버려 `dropped`에 남는지, 그 이름이 기준값까지 닿는지. 코퍼스 밖 요구 거절: 사양 표에 없는 성질 → `not_found`, TSC 아닌 제조사 → `part_missing`, 확인 안 된 개정판 → `revision_missing`이 묻지 않고 판정 보고로 나오는지, 사양 표 항목 · TSC · 확인된 개정 코드는 통과하는지, 멀티 그래프에서 대체 부품 에이전트가 그 사유로 답 검사를 지나 거절로 끝나는지, 거절 문구가 있는 품번을 없다고 하지 않는지. 가짜 LLM · 가짜 사양 표
- `test_facts_lookup.py` — 사실 확인이 MCP 도구 응답(가짜 함수)으로 `Facts`를 만드는지 · 확인할 것이 없으면 도구를 안 부르는지
- `test_agents.py` — RAG 에이전트 하위 그래프: 지시서 검색어 · 품번 필터로 찾고 LLM 1번으로 답하기, 역할은 검색 없이 넷리스트로, 근거 없음 → 다른 검색어로 한 바퀴 더(상한 2) → 못 찾음, 가짜 · 빠진 인용 막기와 일부만 답함, 다른 품번 줄 거르기, 검색 장애 · 품번 필터 안 0건(필터 풀기), 정격으로 품번 찾기 · 제너 최소 · 최대 창. 사실 확인 · 거절 문구(일상어) · 판정 답 틀(확인 안 됨이어도 찾은 값 · 빠진 값 · 주의, 찾기 0개)
- `test_docs_agent.py` — RAG 에이전트: 물은 품번이 변형 품번(SMAJ6.5CA 등)이면 품번 규칙 주석(양방향 모두 적용 · IR 한도 2배)을 한 번 더 찾아 붙이는지, 표 주석 카드를 다른 품번 줄로 거르지 않는지(가짜 검색)
- `test_supervisor.py` — Supervisor가 LLM에 주는 글(질문 · 대상 · 사실 · 고를 수 있는 에이전트), 형식 실패 거절, 지시 칸 · 호출 1번 세기, 대체 부품이 꺼지면 RAG로, 갈림 함수가 갈 노드 이름을 돌려주는지, 답 검사(가짜 인용 · 인용 없음 · 판정 답 틀 · 이미 거절), 프롬프트가 에이전트 하나를 고르고 할 일 목록 · 재계획 말이 없는지. 가짜 LLM
- `test_contracts.py` — Supervisor 지시서 모양 검사(거절 사유 없음 · reply 없음 · 지시 없음 · 판정에 정격 질문 · 검색어 없는 RAG · 없는 길 거부), 이유 코드 분류, 상한 숫자(검색 2)
