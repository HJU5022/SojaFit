# 다이오드 정격 해석과 회로 연결 설명

## 적용 상황

핵심 요청이 정격·특성 조회이면 S1, 대상 주변 넷의 연결·역할 설명이면 S2를 적용한다. 두 질문이 섞여 있으면 데이터시트로 확인할 사실과 넷리스트로 확인할 사실을 구분한다. 생성 프롬프트의 출력·인용·근거 부재 처리를 따른다.

먼저 무엇을 확인해 달라는 질문인지 정한다. 값 조회, 특정 조건의 값, 보장값, 연결 사실, 역할 해석을 구분한다. 실제 적합성·보호 성능·최종 대체 판정을 요구하는 질문을 단순 값 조회나 연결 설명으로 바꾸어 답하지 않는다.

## S1 정격·시험 조건 해석

### 확인 순서

1. 질문이 요구하는 속성과 값 종류를 확인한다. 근거의 값이 MAX·TYP·MIN 중 무엇인지, 단발·반복·연속 중 어떤 동작을 다루는지 구분한다.
2. 값과 연결된 시험 조건·각주를 함께 읽는다. 전류·온도·펄스 폭·파형·듀티가 명시되어 있으면 유지한다. 조건의 대응은 근거의 명시적인 표기·설명으로 확인하며, 숫자 비교나 단위 환산으로 같다고 판정하지 않는다.
3. 핵심 요청에 답할 근거가 있는지 아래 상황으로 나눈다. 주변 값이나 설명이 있다는 이유만으로 요청한 값도 있다고 취급하지 않는다.

| 상황 | 판단과 답변 범위 |
|---|---|
| 요청한 정격·특성값과 시험 조건이 문서에 있음 | 값 종류와 문서의 시험 조건을 함께 설명한다. 문서 조건을 사용자 회로의 조건으로 간주하지 않는다 |
| 문서 정격은 있으나 사용자 동작 조건이 없음 | 정격 조회에는 답한다. 실제 회로 적합성이나 그 조건에서 계속 동작할 수 있다는 결론은 내리지 않는다 |
| TYP만 있는데 보장 MAX/MIN을 요청함 | 전형값을 보장값으로 바꾸지 않는다. 핵심 요청에 답할 근거가 없으므로 기본 프롬프트의 근거 부재 처리를 따른다 |
| 특정 시험 조건을 요청했으나 그 조건의 값인지 확인할 수 없음 | 다른 시험 조건의 값을 요청 조건의 값으로 제시하지 않는다. 보간·외삽·조건 변환을 하지 않는다 |
| 값은 보이지만 필요한 각주가 제공되지 않음 | 조건을 추측하지 않는다. 각주 없이는 요청한 값의 적용 범위를 확인할 수 없다면 근거 부재로 처리한다 |
| 전형 곡선·그래프만 있고 보장 정격을 요청함 | 곡선 경향을 보장값으로 확대하지 않는다. 표에 없는 보장값을 만들어내지 않는다 |
| 단발 서지 값으로 연속 동작이나 반복 펄스 적합성을 요청함 | 서로 다른 동작 조건을 대체하지 않는다. 확인된 정격만으로 요청한 동작을 보장하지 않는다 |

답할 수 있는 값에는 근거의 한정을 유지한다. 절대 최대 정격을 권장 동작점으로 설명하지 않는다. 요청 자체가 보장값·실측값·적합성 결론인데 이를 확인할 수 없으면 주변 정격을 덧붙여 핵심 요청에 답한 것처럼 만들지 않는다.

## S2 회로 연결 설명

### 확인 순서

1. 대상 부품이 근거에 있는지 확인하고 핀별 연결 넷과 이웃 부품을 읽는다. 연결 사실은 넷리스트에서 확인한다.
2. 핀의 기능·방향이 명시되어 있는지 확인한다. 핀 번호만 있으면 번호에 A/K 의미를 임의로 부여하지 않는다. 넷 이름에 VIN·GND 등이 있다는 이유만으로 전압·전류 방향을 확정하지 않는다.
3. 연결 사실, 그 연결이 뒷받침하는 역할 해석, 실제 동작 확인을 구분한다. 역할 해석을 설계자의 확정 의도나 실제 동작 측정으로 표현하지 않는다.

| 상황 | 판단과 답변 범위 |
|---|---|
| 대상의 핀·넷·이웃 연결이 제공됨 | 직접 확인한 연결을 설명한다. 전원 경로를 물으면 제공된 연결로 이어지는 범위까지만 순서를 설명한다 |
| 일부 주변 넷만 제공됨 | 확인된 연결은 설명하되 회로 전체를 보았다고 말하지 않는다. 보이지 않는 우회 경로·부품·전원을 추가하지 않는다 |
| 핀 번호는 있으나 기능이나 A/K 방향이 불명확함 | 번호와 넷의 연결까지만 설명한다. 극성·전도 방향을 확정해야 하는 핵심 질문이면 근거 부재로 처리한다 |
| 연결이 특정 역할 해석을 뒷받침함 | 확인된 연결 사실 뒤에 해석임을 구분해 설명한다. 넷 이름이나 부품 기호 하나만으로 역할을 확정하지 않는다 |
| 대상 연결 자체가 없거나 설명이 서로 충돌함 | 다른 부품으로 대체해 설명하거나 유리한 설명 하나를 선택하지 않는다. 핵심 요청을 확인할 수 없으면 근거 부재로 처리한다 |
| 실제 전류·온도·파형·보호 성능·대체 적합성을 요청함 | 넷리스트의 연결 사실만으로 동작을 보장하지 않는다. 연결 근거만으로 핵심 요청을 확인할 수 없으면 근거 부재로 처리한다. 수치·단위 비교와 최종 대체 판정은 judge의 책임으로 남긴다 |

## 복합 질문

데이터시트 값은 문서가 확인하는 범위, 연결은 넷리스트가 확인하는 범위에서만 사용한다. 연결이 있다는 사실로 문서의 보장값을 채우거나 문서 정격으로 실제 회로 동작을 확정하지 않는다. 핵심 요청이 최종 적합성 판단이면 값 조회·연결 설명으로 바꾸어 답하지 않고 기본 프롬프트의 해당 처리를 따른다. 되묻기 절차나 판정 규칙을 이 Skill에서 새로 만들지 않는다.
