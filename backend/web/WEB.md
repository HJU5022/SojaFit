# web

## 역할
- 이 폴더: 로그인·입력·승인·견적 화면을 둘 자리입니다. 지금은 화면 코드가 없고 화면 설계 초안(`design.md`)만 있어 브라우저에서 실행되는 것이 없습니다.
- 넣는 것: 화면 설계 문서(`design.md`), 그리고 화면을 만들 때 쓸 템플릿(`templates/`)과 정적 파일(`static/`). `templates/`·`static/`은 아직 없습니다. 화면을 FastAPI가 직접 내줄지 별도 프론트 앱으로 만들지는 정하지 않았고, 정하면 `docs/adr/`에 기록합니다.
- 넣지 않는 것: API 로직과 라우트(`backend/main.py`, `backend/auth.py`), 판정 로직(`backend/judge/`), 그래프(`backend/graph/`).
- 담당: 서비스·운영

## 파일
- `WEB.md` — 이 폴더 설명
- `design.md` — 화면 목록(로그인·입력·판정 결과·승인·견적서)과 디자인 원칙 초안. 상호작용·색·글꼴은 "정할 것"으로 비어 있습니다
- `templates/` — 아직 없음 (화면을 만들 때 추가)
- `static/` — 아직 없음 (화면을 만들 때 추가)
