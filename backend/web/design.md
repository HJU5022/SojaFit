# 화면 디자인 규칙

현재 검토 범위의 브라우저 화면은 FastAPI가 같은 출처로 제공하는 로그인·질문 화면입니다. 사용자는 이메일·비밀번호로 로그인하고 질문 한 건의 답을 확인한 뒤 로그아웃합니다. 질문과 답은 저장하지 않습니다. 이 구조는 요청자 선택을 반영했으며 조장 ADR 승인 전에는 평가용 시연안입니다.

## 화면 목록

| 화면 | 하는 일 |
|---|---|
| 로그인·질문 | 사전 계정으로 로그인하고 공통 데이터시트 코퍼스에 질문합니다. 질문·답변·대화·기억은 저장하지 않습니다 |
| 입력 | KiCad 넷리스트를 올리고 바꿀 부품을 고릅니다 |
| 판정 결과 | 회로 역할, 대체 조건, 후보별 대체 판정과 근거를 보입니다 |
| 승인 | 견적서를 저장하기 전에 사람이 확인하고 승인합니다 |
| 견적서 | 승인된 견적서를 봅니다 |

## 원칙

- 대체 판정 5종은 SPEC 3절의 화면 표기를 그대로 씁니다.
- 판정마다 근거(데이터시트의 쪽·표·행이나 공개 문서의 절)를 판정 바로 옆에 보입니다.
- 결과 화면마다 "같은 동작은 보장하지 않는다"를 보입니다.
- 패키지가 달라 기판 수정이 필요한 후보는 판정과 따로 표시합니다.

## 상호작용

- 로그인 실패는 자격 증명을 되돌려 보이지 않는 공통 안내를 표시합니다.
- 로그인 후 질문 입력과 답변을 한 화면에 표시합니다. 답변은 일반 텍스트로 보여 줍니다.
- 로그아웃 성공 시 화면의 이메일·비밀번호·질문·답을 지웁니다.
- 회원가입·비밀번호 재설정·프로필·대화 목록은 제공하지 않습니다.
