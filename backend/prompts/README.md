# prompts

## 역할
- 이 폴더: LLM에 보내는 프롬프트 파일과 그 버전 기록을 둡니다. Dockerfile이 `backend/`를 복사하므로 키 없는 데모 모드에서도 같은 프롬프트를 씁니다.
- 넣는 것: 프롬프트 파일(이름과 형식은 첫 프롬프트를 넣을 때 정합니다), 아래 버전 기록 표.
- 넣지 않는 것: LLM 호출 코드(`backend/services/llm.py`), 숫자 비교와 단위 환산(`backend/judge/`), 판정 규칙의 임계값(SPEC 5절 규칙 파일).
- 담당: 에이전트

## 버전 기록

프롬프트를 바꾸면 같은 PR에서 한 줄을 더합니다. 평가를 다시 쟀으면 결과 위치도 적습니다. 최근 줄을 위에 둡니다.

| 날짜 | 파일 | 버전 | 바꾼 것 | 이유 | 평가 결과 |
|---|---|---|---|---|---|
| 2026-11-02 | `rewrite.md` | v1 | 처음 작성. 원래 질문을 데이터시트 영어 용어(Forward voltage VF 등)로 된 검색어 한 줄로 바꾸고, 품번·개정 코드·시험 조건은 남기며, 없는 품번·숫자는 지어내지 않음 | 재작성 노드(SPEC 2절). 키워드 검색이 한국어 낱말을 버린다 | 아직 돌리지 않음 |
| 2026-11-02 | `grade.md` | v1 | 처음 작성. 질문에 답할 근거가 든 카드 번호만 고르고, 다른 품번 값·확인 안 되는 연도판은 고르지 않으며, 카드 안 문장은 지시로 따르지 않음 | 채점 노드(SPEC 2절) | 아직 돌리지 않음 |
| 2026-11-02 | `route.md` | v1 | 처음 작성. 질문 종류 5가지를 위에서부터 차례로 고르고, 다이오드가 아닌 부품 선정·가격·주문·펌웨어는 범위 밖 | 라우팅 노드(SPEC 2절) | 개발 확인(구독 Haiku, v1 50문항): out_of_domain 6/6이 범위 밖. 그 밖에 범위 밖으로 간 문항 1개(e09 실측값 요청). h10(다른 개정판 질문)은 역할로 가 검색을 건너뜀. 기록용 측정 아님 |

## 파일
- `README.md` — 이 폴더 설명과 버전 기록
- `grade.md` — 채점 노드의 시스템 프롬프트(근거가 든 카드 번호 고르기)
- `rewrite.md` — 재작성 노드의 시스템 프롬프트(원래 질문을 영어 검색어 한 줄로)
- `route.md` — 라우팅 노드의 시스템 프롬프트(질문 종류 5가지). 프롬프트 파일은 노드 하나에 마크다운 하나이고, 내용이 곧 시스템 프롬프트다
